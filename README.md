# Trial of the Ages: Last Ember

人類が絶滅寸前に追いやられた世界で、**最後の残り火（🔥）**を絶やさないよう、3度の破滅的な試練を乗り越えて 50 ターン完走を目指す箱庭内政パズルストラテジー + カード構築ゲーム。

---

## 🎯 核心デザイン哲学（最優先原則）
- **「強力なユニットを生産して敵をオーバーキルする戦闘ゲームではない」**
- **「知恵をしぼり、手札・回転・配置を試行錯誤して、場の産出（リソース）が増加していくよう領土・箱庭を育てる『内政成長の純粋な気持ちよさ』に最大価値を置く」**
- **【最根本原則】試行錯誤して状況を作り出したプレイヤーは最高に報われるべきである**
- **「積み上げ巻き戻し破壊の完全禁止」**（ランダム天変地異による土地・建造物の永続消失ゼロ）
