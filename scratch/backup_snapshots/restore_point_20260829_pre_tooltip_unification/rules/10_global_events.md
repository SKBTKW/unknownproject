# 10. グローバルイベント (Global Events) 仕様書

> **Status:** Test / Draft
>
> 50ターン中に発生する一時的な世界変化。
> プレイヤーの計画をランダムに破壊するのではなく、
> 数ターンの間「カード・資源・盤面の価値」を変化させ、
> 既存の計画の優先順位を揺らすことを目的とする。

---

## ─── 🌍 基本仕様 ───

### 発生原則

- 毎ターン確定ではなく、ターン開始時に発生判定を行う
- 発生するイベント候補は現在の盤面・資源・Stage・試練状況などを参照する
- イベント発生後は一定ターンの共通クールタイムを設ける
- クールタイム中は原則として新たなグローバルイベントを発生させない
- 同一イベントの短期間での再発を防止する
- 1ラン50ターン中 **4〜7回程度** の発生を初期テスト目標とする
- イベントの存在によってプレイヤーの長期計画そのものを強制破壊しない
- 「今の計画を続けるか、一時的に別のものを優先するか」を悩ませる

### 発生タイミング

完全ランダムではなく、前回イベントからの経過ターンによって発生率を変化させる。

テスト初期値：

| 前回イベントからの経過 | 発生率 |
| :---: | :---: |
| 0〜2T | `0%` |
| 3T | `5%` |
| 4T | `10%` |
| 5T | `20%` |
| 6T | `35%` |
| 7T以降 | `50%` |

※ 数値はテスト用。プレイテンポを見て調整する。

### イベント選択

イベント発生が決定した後、

1. Stage条件
2. 盤面条件
3. 資源条件
4. 試練までの残りターン
5. イベント固有クールタイム

を確認し、条件を満たしたイベントのみ候補化する。

候補イベントからWeight付き抽選を行う。

つまり、

**「発生するか」**
→ Event Director

**「何が発生するか」**
→ 現在の世界状態を参照したEvent Selector

として処理を分離する。

# ─── ⚔️ 亜人襲撃 専用ルール ───

《亜人襲撃》は通常の環境イベントとは異なり、以下の固有制限を持つ。

- 第1試練終了までは発生しない
- 第1試練終了時にイベント候補プールへ追加
- 次の試練まで **5ターン以内** の場合は候補から除外
- 発生後は **8ターン** の専用クールタイム
- 通常の試練と完全に同じ処理にはしない
- 迎撃方向は1方向のみ
- 本試練より大幅に低い制圧力を使用
- 盤面・🛡️・地形戦術など既存の防衛要素を利用する
- プレイヤー操作量は本試練より少なくする

目的は「第4、第5の試練」を追加することではなく、

**第1試練以降、人類が常に亜人勢力から認識されている**

ことをゲームプレイで表現すること。

# ─── 🔗 イベント間Weight変化 ───

イベントチェーン専用システムは作らない。

既存のEvent Selectorに一時的なWeight補正を与えることで、
出来事同士の因果関係のみ表現する。

テスト例：

| 発生イベント / 状態 | 後続変化 |
| :--- | :--- |
| **寒波**終了時に🌾不足 | 食料不安系イベントWeight上昇 |
| **寒波**を十分な備蓄で突破 | 社会安定系イベントWeight上昇 |
| **豊穣の季節**終了時に🌾大量余剰 | **《新たな世代》Weight上昇** |
| 試練で大損害 | **《復興の機運》Weight上昇** |
| 試練を圧倒的勝利 | 勝利・社会活性系イベントWeight上昇 |
| **亜人襲撃**発生 | 《亜人襲撃》専用CT開始 |

# ─── 🕰️ 平穏期間 ───

「何も起こらない期間」もイベントテンポの一部として扱う。

イベント発生後は最低3ターンの発生禁止期間を設け、

**イベント**
↓
**平穏**
↓
**イベント**

というリズムを作る。

プレイヤーに毎ターン新しいルールを読ませない。

グローバルイベントそのものではなく、

**「今、このタイミングで世界が変化した」**

ことを印象付ける。

# ─── 📜 年表 ───

ゲーム終了時、発生した主要グローバルイベントと試練を時系列表示できるよう、
イベント発生履歴を保存する。

表示例：

T08　豊穣の季節  
T16　寒波  
T20　第1の試練  
T27　亜人襲撃  
T32　新たな世代  
T38　第2の試練  
T44　復興の機運  
T50　第3の試練

目的は50ターンを単なるゲーム進行ではなく、

**「この英雄が人類を三度の試練から救った時代」**

として振り返れるようにすること。

# ─── 🧪 初期テスト項目 ───

1. 50ターン中4〜7回程度のイベント発生になるか
2. イベントが連続してプレイヤーを拘束しないか
3. 同じイベントばかり発生しないか
4. 《寒波》によって実際にカード3択の評価が変化するか
5. 《豊穣の季節》が単純な無料資源ボーナスになっていないか
6. 《新たな世代》など盤面状態由来イベントに因果関係を感じられるか
7. 第1試練後に《亜人襲撃》が解禁されることでStage進行を体感できるか
8. 《亜人襲撃》が「小さい試練の繰り返し」になって作業化しないか
9. イベントによるカードWeight変化をプレイヤーが体感できるか
10. イベントがプレイヤーの計画を破壊するのではなく、優先順位を変化させているか
11. イベント終了後に通常状態へ戻ったことがUI上で明確か
12. 終了時の年表を見て、そのラン固有の出来事を思い出せるか

## テスト段階での設計目標

グローバルイベントの成功基準は、

**「知らないイベントがたくさん出てきて面白い」**

ではない。

同じカード・同じ土地・同じ資源であっても、

**《寒波》の最中に引いたカードと、
《豊穣の季節》の最中に引いたカードでは価値が違って見える**

状態を作ることを第一目標とする。

カードそのものの種類だけに依存せず、

**盤面 × 資源 × 試練 × ロール × グローバルイベント**

によって毎ラン異なる意思決定を発生させる。
