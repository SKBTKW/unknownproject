# The Age of Trials — ルール

このディレクトリは、**The Age of Trials を初めて読む人が「何をするゲームなのか」「何を考えて遊ぶのか」を短時間で理解するための入口**です。

実装・数値・例外条件まで含む詳細仕様の正本は、既存の [`rules/`](../rules/) にあります。

ここでは、現行仕様を次の3つに分けて説明します。

1. [`01_プレイマニュアル.md`](./01_プレイマニュアル.md)  
   1 Verseで何をするか、資源、土地、Offering、Trialまでをプレイヤー目線で説明します。

2. [`02_ゲーム概念.md`](./02_ゲーム概念.md)  
   Verse、Stage、開発、地帯化、連携、Trial、残火など、ゲーム全体を構成する主要概念の関係を説明します。

3. [`03_コンセプト.md`](./03_コンセプト.md)  
   「盤面＝未来への投票」「これまで作ってきたものに、戦う意味を与える」など、本作の中心思想を説明します。

---

## 一言でいうと

**土地とカードで50 Verseを生き延び、築いた盤面そのものを使って3度のTrialを迎え撃つ、ソロ向けストラテジー / カード / ローグライトゲームです。**

プレイヤーは強力な軍隊を量産して敵を押し潰すのではありません。

平時に、

- どの土地を開発するか
- どの資源を伸ばすか
- どこを地帯化するか
- どの地帯を連携するか
- どのカードを今使い、何を保留するか
- どこに防衛力を残すか

を積み重ねます。

その選択の結果が、後のTrialでそのまま戦場になります。

> **盤面 = 未来への投票**

---

## ゲームの最終目的

基本ランは **50 Verse**。

その間に3度の大きなTrialが訪れます。

Verse 50終了時まで人類の希望である **🔥残火** を1以上残せば完走です。

🔥が0になれば敗北です。

---

## まず覚える5つの資源

| 資源 | 意味 |
| :--- | :--- |
| 🔥 残火 | 人類の生存と希望そのもの。0で敗北 |
| 🌾 食料 | 毎Verseの維持と一部カードに必要 |
| 🧱 資材 | 建設・軍事・改良の主要コスト |
| 🛡️ 防衛 | Trialで迎撃へ投入する有限資源 |
| ✨ 神秘 | 神秘カードや非常時の補填に使う |

---

## 基本の流れ

```text
Offeringを見る
↓
土地を開発する / カードを使う / 必要ならHoldする
↓
盤面を形成する
↓
地帯化・連携・改良を狙う
↓
NEXT VERSE →
↓
産出・維持・イベント・次Offering
↓
警戒が高まり、Trialへ
↓
作ってきた盤面で迎撃
```

Trial専用の手札を突然渡されて戦うゲームではありません。

> **Trialでは新しい力を与えない。これまで作ってきたものに、戦う意味を与える。**
