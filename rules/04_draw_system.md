# 04. ドロー ＆ 手札オファリングシステム概要

## 🔒 1. 段階的盤面拡大 ✕ レアリティ (C, UC, R, L) ドロー解禁制限

盤面の拡大（5×5 ➔ 7×7 ➔ 8×8）に応じて、手札オファリングにドロー出現するレアリティが解禁されます。

* **Stage 1 (5×5 盤面 / T1〜15)**: **`C (1×1)`** および **`UC (1×2, 1×3)`** のみドロー出現。（※🔒 R・L はドロー不可）
* **Stage 2 (7×7 盤面 / T16〜30)**: **`🔓 R (1×4 4マスブロック)`** が解禁・ドロー出現！
* **Stage 3 (8×8 盤面 / T31〜50)**: **`🔓 L (2×2 正方形)`** が解禁・ドロー出現！

---

## 🚫 2. 湖カードのドロー完全除外

* 独立水域「湖」カードは手札ドローのオファリングから完全に削去されました。
* 湖・川は、本営から3マス離れた奥地へ2マス以上のブロックを配置した際に発動する**「1プレイ1回限定の川・源流自動発見ロール」**でのみ盤面に露出・生成されます。

## 🤝 【現行検討案とのコンペア＆すり合わせ追記】

* **6カテゴリ ドロー構造の継承**:
  1:土地, 2:川, 3:施設, 4:社会, 5:神秘, 6:軍事 の6カテゴリから選ばれた3枚の手札カードオファリングをそのまま継承。
* **手札カードの高視認性大型化 (145px幅)**:
  手札の各カードに4×4ミニドット絵プレビュー（R回転連動）と見込み合計産出量を表示。
* **事故防止 ＆ 戦略ストック (マリガン ＆ 保留スロット 0/3)**:
  * 🎲 **マリガン (リソース消費アクション)**:
    - **1回につき -1 🔥 (残り火) 消費**。無償枠は存在せず、🔥 が 0 の場合は実行不可。
  * **保留枠数**: 最大 3 枠 (0/3 〜 3/3)
* **ペナルティ**: 保留スロットにカードが存在するターン開始時、維持費として `-1 🔥` 自動消費。
* **ドローエリア配置**: 画面下部フッター内の**画面横中央（センタリング）**に配置。
* **右クリック回転**: 盤面・カード上で右クリックで 90度回転。**ボタンを離しても回転状態を 100% 永続維持**。
* **進行ログ位置**: 右サイドパネル下部に配置し、**縦方向（上下スライド）アコーディオン格納**に対応。
