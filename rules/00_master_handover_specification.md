## 📋 1. ゲーム概要 ＆ 核心デザイン哲学
- **タイトル**: Trial of the Ages: Last Ember
- **プレイ時間**: 50ターン固定（シングルプレイヤー）
- **ジャンル**: ローグライク要素を持つ箱庭内政パズルストラテジー + カード構築
- **世界観**: 人類は絶滅寸前に追いやられ「最後の残り火（🔥）」を守っている。3度にわたる破滅的な試練を耐え抜き、50ターン完走を目指す。
- **勝利条件**: 50ターン終了時に 🔥 が残っている（3度の試練の成否は問わない）。
- **敗北条件**: 🔥（残り火）が 0 になる。
- **最核心デザイン哲学**:
  - **「強力なユニットを生産して敵をオーバーキルする戦闘ゲームではない」**。
  - **「知恵をしぼり、手札・回転・配置を試行錯誤して、場の産出（リソース）が増加していくよう領土・箱庭を育てる『内政成長の純粋な気持ちよさ』に最大価値を置く」**。
  - **【最根本原則】試行錯誤して状況を作り出したプレイヤーは最高に報われるべきである**。

## 🗺️ 2. 盤面 ＆ 段階的成長仕様
- **ロール選択**: 🛡️ 将軍 / ✨ 預言者 / 🌾 開拓者
- **毎ターン進行**: ドロー ➔ 判断 ➔ 行動（🔥消費）
- **🌊 水脈 (川) の動的発生・延伸 ＆ 🚫 本営包囲禁止ガード (確定仕様)**:
  - **外周エリア (青色領域 / 5×5最外周16マス) での低確率湧出**:
    - 本営周囲の内郭 3×3 ではなく、**最外周 (青色領域) または盤面外縁へ資源・土地ブロックを配置した際、低確率で「川 (水脈 GL1+)」が自動発生・湧出** する。
  - **🚫 本営包囲禁止ガード (環濠化・孤立防止ルール)**:
    - 川が本営 (C3) を全周包囲 (ぐるりと一周) して本営が水没孤立することは **システム的に100%禁止**。
    - **本営隣接4マスの川制限**: 本営に上下左右で隣接する4マスのうち、川が存在できるのは **「最大2マスまで」**。本営の周囲には必ず最低2方向以上の陸路が維持される。
    - 流路アルゴリズム: 川は本営を周回せず、「外縁 ➔ 本営の脇を通過 ➔ 反対側の外縁・海へ流出する」直線/L字流路を維持。
  - **防衛ラインとのシナジー**:
    - 外周に川が発生することで、マップ外縁付近に自動的に「渡河防衛ライン」が形成され、敵の侵攻ベクトルに対する強力な迎撃ポイント (渡河攻撃) が自然構築される。
  - **川の延伸・海流**:
    - 川がすでにある場合、隣接マスへのブロック配置で川が海・湖・外縁に向かって自然延伸する。
    - 2×2 マージ土地における『大河・デルタ地帯』昇格ルールと完全互換。
  - **Stage 2 (Turn 16〜35 / 第1試練突破後)**: **7×7 盤面**（本営中央 4,4） ＋ 本営産出 **1.4倍** / 3マス以下のブロック出現
  - **Stage 3 (Turn 36〜50 / 第2試練突破後)**: **9×9 盤面**（本営中央 5,5） ＋ 本営産出 **1.8倍** / 4マス大型ブロック全解禁
  - 本営は物理的に 1×1 マスを維持し配置齟齬を完全排除。

## 🏰 3. 本営周囲8マス（王都圏）配置ボーナス 【代案A】
- **【代案A】固定加算 (+1/マス) 方式**: 
  - 本営（中央1×1マス）を囲む **周囲8マス（3×3王都圏）** に配置された土地マスは、その土地が持つ全産出項目に **`+1 / マス` の固定加算ボーナス** が付与される。
  - 例: 草原 (`🌾4`) ➔ **`🌾5`** / 森 (`🌾2 🧱2 🛡️2`) ➔ **`🌾3 🧱3 🛡️3`**
- **【王都コンプリートボーナス】**:
  - 周囲8マスがすべて土地で埋め尽くされると「王都完成！」のアナウンスとともに、本営の全産出量が **1.5倍** へ永久強化＋🔥回復。
