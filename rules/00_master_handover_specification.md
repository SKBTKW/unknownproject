## 📋 1. ゲーム概要 ＆ 核心デザイン哲学

- **タイトル**: Trial of the Ages: Last Ember
- **プレイ時間**: 50ターン固定（シングルプレイヤー）
- **ジャンル**: ローグライク要素を持つ箱庭内政パズルストラテジー + カード構築
- **世界観**: 人類は絶滅寸前に追いやられ「最後の残り火（🔥）」を守っている。3度にわたる破滅的な試練を耐え抜き、50ターン完走を目指す。
- **勝利条件**: 50ターン終了時に 🔥 が残っている（3度の試練の成否は問わない）。
- **敗北条件**: 🔥（残り火）が 0 になる。
- **最核心デザイン哲学**:
  - **「強力なユニットを生産して敵をオーバーキルする戦闘ゲームではない」**。
  - **「知恵をしぼり、手札・回転・配置を試行錯誤して、場の産出（リソース）が増加していくよう領土・箱庭を育てる『内政成長の純粋な気持ちよさ』に最大価値を置く」**。
  - **【最根本原則】試行錯誤して状況を作り出したプレイヤーは最高に報われるべきである**。

  - **T1〜15 は完全無風 (純粋な内政・土地パズル集中期間)**。途中で練習襲撃などのチュートリアル割り込みは一切挟まない。
  - **T15 の第1試練はぶっつけ本番** とするが、**7大セーフティネット (第1試練初見保護: 敗北しても死に体化せず救済バフ獲得)** によって初心者保護を完備。
- **👹 亜人襲撃 (局地侵攻) の確定発生メカニクス (T16以降解禁 / 急速拡大カウンター)**:
  - **世界観・亜人の認知設定 (秘匿・露出概念は保留)**:
    - 亜人側は **ゲーム開始時点で人類の存在をすでに認知** している。ただし最初は極小規模なため放置・軽視している。
    - 人類が **急激な勢力伸長 (領土の急速拡大・富の過剰蓄積)** を起こした瞬間、「放置すると危険な脅威」と認識を一変させ、害虫駆除・先制攻撃として襲撃を開始する。
  - **解禁タイミング ＆ 制限**:
    - **第1試練突破後 (Turn 16以降) から本格発生解禁**。
    - **試練前後3ターンのプロテクト (発生不可)** ＆ **襲撃解決後3〜5ターンのインターバル (連続発生防止)** に厳格準拠。
- **🏛️ 試練 (Trial) の真の存在意義 ＆ 産出インフレの抑制制御メカニクス (確定本質仕様)**:
  - **試練の真の役割【インフレを留める減圧弁】**:
    - 平時ターンに土地配置で加算・肥大化し続ける毎ターンの産出と総蓄積量 (富) を、**定期的な「試練 (Turn 15, 30, 50)」の防衛・迎撃・復旧コストとして大量消費・間引き・リバランス** する。
    - 平時内政での「成長・加算の爽快感」は一切削ぐことなく、試練が肥大化した富をデフレーション (適正化) させることで、ゲーム全体のインフレを安全に留める完璧な循環構造。
- **⚔️ 敵制圧力 (試練難易度) の確定算出公式 (ユーザー画像『試練の流れ①』完全準拠)**:
  - **確定公式**:
    $$\text{制圧力} = \text{場の防衛力} + \text{場の産出総蓄積量の } 30\% \text{ (仮)}$$
    *(※例: 場の防衛力合計が 60 (10+40+10)、場の産出総蓄積量が 300 の場合 ➔ $60 + 300 \times 0.3 = \mathbf{160}$)*
  - **制圧力の目標値バランス**:
    - **「場の防衛力が制圧力をやや上回る 〜 結構上回るくらいの振れ幅」** となるよう適切なスケーリング係数を調整。
    - プレイヤーが場の防衛力を高め、産出と防衛のバランスを試行錯誤していれば、制圧力を上回って自力で完全防衛できるゲームバランス。
- **⚔️ 迎撃地点選定 ✕ 二段階防衛フロー (防衛地点での削り ➔ 本営での最終解決)**:
  - **二段階防衛構造 (二段構え)**:
    - **【第1フェーズ (前衛削り)】**: 指定した防衛地点 (例: C1, C4) にて地形自動戦術 (渡河・逆落とし・伏兵) を駆使し、**本営に到達する敵の「制圧力」をいかに大きく削る (減衰させる) か** を競う。
    - **【第2フェーズ (本営決戦)】**: 防衛地点ですり減った残存敵軍が最終的に **本営 (C3) に到達し、本営の防衛力にて最終解決・防衛判定** を受ける。
  - **場の強さに応じた動的難易度スケーリング**:
    - 試練の敵制圧力は **現在の場の強さ (産出量・開発度) から動的算出**。ドロー運が悪く場が弱ければ敵も相応に弱くなるため、地勢運による「詰み」は発生しない。
  - **迎撃地点ホバー事前プレビュー (UI/UX)**:
    - プレイヤーが防衛地点にマウスオーバーした際、**「前衛で敵制圧力を何ポイント削れるか」「本営に到達する残存敵はいくつか」「本営での最終防衛結果」がリアルタイムに事前明快表示** される。
  - **地理戦術の具体的発動ルール**:
    - **高度優位 (H2/H3 ➔ H1)**: 防衛側の高度が相手を上回る ➔ **『逆落とし突撃 (仮)』(自軍防衛力大バフ)** が発動。
    - **水脈遮断 (川の介在)**: 彼我の間に川が存在 ➔ **『渡河攻撃 (仮)』(敵制圧力半減デバフ)** が発動。
    - **森林遮蔽 (GL2+)**: 森の存在するマスを指定 ➔ **『伏兵奇襲 (仮)』(敵作戦無効化)** が発動。
- **🏛️ 都市 (拠点) のターゲット引き寄せ ＆ 損害処理 (身代わりデコイ)**:
  - **ターゲット優先順位**: 敵は本営を狙うが、**進行ルート上に都市 (拠点) がある場合は都市へ標的を変更** して攻撃する。
  - **本営の完全ガード**: 都市が身代わりとなるため、その攻撃で本営は一切の損害を受けない。
  - **都市の損害処理 (機能停止 ＆ 補給線一時切断)**:
    - 都市は破壊・滅失せず **「荒廃 (休眠 / 3〜5ターン)」** 状態になるのみ。
    - 休眠中は「本営との街道 1.5倍 補給線ボーナス」が **1.0倍 (一時消滅)** となり、都市固有機能がストップする。
    - 時間経過による自動回復、または少量の `🧱` や `🔥` 消費で即時修理が可能。
