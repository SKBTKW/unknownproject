# 05. 試練 ＆ 空間防衛 ＆ 敵制圧力 確定仕様書

## ⚔️ 1. 試練 (Trial) の根本定義 ＆ 3大試練の構造

### 1. 試練の定義
> **試練とは、これまで築いてきた国土・産業・防衛・情報網を使って、亜人の侵攻をどこで、どう止めるかを問う答え合わせフェーズである。**

- 試練専用の別ゲームを始めるのではなく、**平時に形成した盤面そのものを戦場として使用する**。
- 本システムにおける中心命題は常に以下である：
  > **「すべては守れない。どこで迎え撃つ？」**

### 2. 3回の試練の意味（体験 ➔ 適応 ➔ 証明）
本作における3回の試練は、単なる数値チェックではなく、文明の成長曲線とプレイヤーの学習体験に完全に同期した3段階の構造を持つ。

```
第1試練【体験】 ➔ 第2試練【適応】 ➔ 第3試練【証明】
```

1. **第 1 試練：体験 (Experience)**
   - 自分が作った国土が「戦争ではどう見えるか」を知るフェーズ。
   - 地形、迎撃地点、連携、🛡️配分、敵残存制圧力などの意味を初めて体験する。
2. **第 2 試練：適応 (Adaptation)**
   - 第1試練で見えた弱点や地政学的課題へ本格的に対応するフェーズ。
   - 軍事施設、軍制、地形誘導、情勢・諜報、街道、連携などを複合的に利用して最適化を図る。
3. **第 3 試練：証明 (Proof)**
   - ここまで完成させた文明と国土全体の集大成を問い、生き残りを証明する最終答え合わせフェーズ。

## 🏛️ 2. Trial性能の4大支柱 ＆ プレイヤー向け最小説明

### 1. Trial性能の4大要素（役割分担）
試練における防衛性能は、以下の4要素へ明確に役割分担される：

| 支柱要素 | 主な役割・意味 |
| :--- | :--- |
| **① 盤面総産出** | 亜人が人類の繁栄・勢力規模を評価する主指標（敵脅威度の算出基準） |
| **② 連携** | 同時に何方面へ迎撃部隊を展開できるか（同時迎撃可能方面数の決定） |
| **③ 🛡️ 防衛力** | 迎撃地点へ投入可能な総戦力（有限な防衛資源のプール） |
| **④ 地形・特殊ブロック・軍制・戦術** | 投入した 🛡️ をどれだけ効率よく運用できるか（戦力倍率・減衰・機動） |

※ **情勢・諜報 (04)** は別途、「有限な迎撃枠と 🛡️ をどこへ使うべきかを知る」ための重要情報網としての役割を担う。

### 2. プレイヤー向け最小説明（4行原則）
複雑な内部計算をプレイヤーに暗記させることを廃止し、Trialの根幹は以下の4行で直感的に理解できる状態を保証する：

> **産出が高いほど、亜人は人類を大きな脅威とみなす。**  
> **連携が発達しているほど、多くの方面へ軍を展開できる。**
> **🛡️は迎撃へ投入できる総戦力。**  
> **地形と戦術を使えば、少ない🛡️でも大軍を止められる。**

## 👁️ 3. 亜人による人類脅威評価 ＆ 敵総制圧力

### 1. 観測可能な表層評価の原則
亜人は人類の潜在能力や内面（心理・備蓄・隠蔽されたカード）まで完全には把握できない。亜人軍司令部は、**主に外から観測可能な表層情報**に基づいて人類の脅威度を評価する。

- **亜人の観測・評価対象**:
  - 盤面総産出（最も重視）
  - 地形配置
  - 街道網
  - 明白な防衛施設（前哨塔、防壁など）
  - 現在露出している防衛力
- **亜人が正確には評価しないもの**:
  - 手札のカード
  - 保留カード（HOLDスロット）
  - 備蓄資源（🌾/🧱/✨）
  - Trial中に使用可能な戦術・介入手段
  - 予備隊 / 騎馬軍の再配置能力
  - 夜襲 / 伏兵 / 総動員
  - 将来的な特殊ブロックの建設余地

> **設計思想**: 「亜人から見える戦力」と「実際にTrialで発揮される戦力」の非対称性を許容し、これをプレイヤーの戦略的欺瞞・戦術運用の余地とする。

### 2. 盤面総産出を主軸とする敵総制圧力
亜人が人類をどれだけ脅威とみなすかは、**盤面の総産出**を主評価とする。産出は「人類がどれだけ繁栄し、生存圏を拡大し、周囲の亜人勢力にとって無視できない存在になったか」を如実に表すためである。

#### 概念的算出モデル
$$\text{敵総制圧力} = \text{Trial基礎脅威} + \text{盤面産出帯による繁栄補正} + \text{亜人勢力補正} + \text{司令官補正}$$

- **旧制圧力公式の完全廃止**:
  - 旧仕様の公式（$\text{制圧力} = \text{場の防衛力} + \text{産出} \times 0.3$）は完全に廃止する。
  - 特に**「防衛力を上げると敵まで同じだけ強くなる」構造を完全に撤廃**し、🛡️は人類側の純粋な防衛資源として独立させる。
- **非線形スケーリング**:
  - 「産出が2倍になれば敵も2倍」という単純比例は採用せず、産出帯（Tier）による段階制や逓減スケーリングを適用して急激なインフレを抑制する。
  - *(※各Trialの基礎値、産出帯スケーリング具体式、勢力補正数値はプロトタイプ初期値としてテストプレイで調整予定)*

## 🛡️ 4. 🛡️ 防衛力の役割（迎撃への総投入戦力）

🛡️（防衛力）は、**「迎撃へ投入できる総戦力」**として扱う。

- **高 🛡️ ＝ 一地点で強い（全方面を守れるわけではない）**:
  - 🛡️ を増やしても、それだけで同時に守れる方面数（迎撃枠）が増えることはない。
  - 例：迎撃可能方面数 `3`、総防衛力 `🛡️ 18` の場合：
    - 東方へ `🛡️ 10`
    - 北方へ `🛡️ 5`
    - 西方へ `🛡️ 3`
    のように、有限な総戦力を各迎撃方面へ配分して戦う。
- **旧仕様の閾値ボーナス廃止**:
  - 旧仕様の「🛡️ 25 / 60 / 80 達成で迎撃ポイント +1」という防衛力依存の迎撃枠増加は完全に廃止する。

## 🔗 5. 連携と街道の役割分担

軍事展開と機動において、連携（異なる地帯間の関係）と街道（交通インフラ）は明確に異なる役割を持つ。

```
【連携】 ➔ その方面へ軍を展開できるか（展開能力・同時迎撃方面数）
【街道】 ➔ 展開した軍をどれだけ速く移動・再配置できるか（機動性・再配置速度）
```

### 1. 連携の役割（同時迎撃可能方面数）
連携（異なる属性の地帯同士の接触）は、**国土の各地域をどれだけ連携させ、人員・物資・情報を複数方面へ同時展開できるか**を表す。Trialにおいて、連携は**「同時に迎撃できる方面数」**を決定づける。

- **迎撃可能方面数（暫定プロトタイプ段階制）**:
  - **基礎迎撃枠**: 1方面
  - **連携 2 以上**: +1方面
  - **連携 4 以上**: +1方面
  - **連携 7 以上**: +1方面
  - *(※最大4方面。数値・閾値はプロトタイプ暫定値でありテストプレイ調整前提)*
- **非線形・上限制・「すべては守れない」の保証**:
  - 連携1本ごとの線形増加ではなく、段階制と上限を設ける。
  - 原則として常に **「敵進軍ルート数 > 迎撃可能方面数」** を維持し、プレイヤーに「どこを捨て、どこを救うか」の決断を迫る。

### 2. 街道の役割（高速機動と両刃の剣）
- 街道は部隊の高速移動・再配置を可能にし、限られた迎撃戦力の機動性を飛躍的に高める。
- **両刃の構造**: 街道は味方だけでなく**敵の進軍コストも大幅に下げる**。自軍の展開を助ける交通網が、敵の電撃的侵攻ルートにもなり得る地政学的リスクを内包する。

## 🗺️ 6. 侵攻ルート配分 ＆ 進軍経路決定（最小進軍コスト方式）

### 1. 総制圧力のルート配分
敵の総制圧力は、侵入方位（複数ルート）へ傾斜配分される。
- **配分例 (総制圧力 100 の場合)**:
  - 東方ルート: `38`
  - 北方ルート: `26`
  - 西方ルート: `21`
  - 南方ルート: `15`
- **配分要因**: 完全ランダムではなく、亜人司令官の進軍ルート（最大配分）、亜人種ごとの地形嗜好、情勢傾向等に基づいて決定される（※内部の詳細計算式はプレイヤーへ完全公開しない）。

### 2. 進軍経路（最小進軍コスト方式）
- **旧仕様のマンハッタン最短経路を完全廃止**:
  - 盤面上のマス目を単純カウントする「マンハッタン距離最短ルート」は完全に撤廃する。
- **進軍コスト最小経路の採用**:
  - 敵軍は **「侵入口から本営 (HQ) までの進軍コスト合計が最も低い経路」** を選択して進軍する。
  - 距離が遠回りであっても、進軍コスト合計が低ければその経路を選択する。

#### 地形ごとの進軍コスト概念（暫定プロトタイプ）
| 地形区分 | 進軍コスト傾向 | 特徴・戦略的意味 |
| :--- | :--- | :--- |
| **街道** | **極めて低コスト** | 最優先で選ばれやすい高速侵入ルート（両刃の剣） |
| **平地 (草原/干拓地)** | **低コスト** | 敵の進軍を妨げず、容易に通行される平坦地 |
| **丘陵** | **中〜高コスト** | 敵の足を鈍らせ、迎撃側が優位に立ちやすい要衝 |
| **森林** | **高コスト** | 隊列を乱し、進軍コストを重くする天然の防壁 |
| **湿原** | **高コスト / 特殊作用** | 泥濘により大軍ほど進軍困難になる低湿地 |
| **山岳** | **通行不可 / 強制迂回** | 侵入そのものを阻み、敵の進軍経路を物理制限する |

*(※各マスの具体的な進軍コスト数値は今後テストプレイにて策定・調整)*

## 🎭 7. 亜人のルート判断 ＆ 戦力偽装（AI原則からの自然発生）

亜人はルートを選択する際、観測可能な情報（進軍コスト、露出した防衛力、防衛施設、地形、街道）に基づいて合理的に判断する。しかし、伏兵、予備隊、騎馬軍、夜襲、隠された戦術カードまでは把握できない。

このAI原則により、専用ゲージや独立システムを用意することなく、以下の **戦力偽装・誘導戦術が自然発生** する：

1. **誘引（実際より弱く見せる）**:
   - 意図的に防衛力を露出させず、進軍コストの低い「湿原・隘路」へ敵を引き込む。
2. **威嚇（実際より強く見せる）**:
   - 前哨塔や強固な防壁を特定方面に配置し、敵軍を別の方位へ迂回させる。
3. **隠し戦力（実戦力のみを高める）**:
   - 表層の脅威評価を変えずに、騎馬の再配置や伏兵戦術によって実迎撃時に敵を叩き潰す。

## 🌲 8. 地形の役割 ＆ 二大防衛思想の両立

### 1. 地形ごとの固有作用（単純な 🛡️+5 方式の廃止）
地形効果を「🛡️+5」のような一律の防衛力加算に統一せず、各地形が独自の軍事的作用（コスト増大、隊列破壊、大軍減衰など）を持つ構造とする。

- **平地**: 進軍をほぼ妨げないが、騎馬軍などの機動展開に適する。
- **森林**: 敵の隊列を乱し、進軍速度を低下させる。
- **湿原**: 泥濘により、大軍（制圧力の高い部隊）ほど激しく消耗・減衰させる。
- **丘陵**: 高所アドバンテージにより、迎撃部隊の戦闘効率を高める。
- **山岳**: 進軍経路そのものを遮断し、敵を特定の隘路へ誘導する。
- **街道**: 敵味方双方に最高速の移動を与える。

### 2. 「防衛力型」と「地形戦型」の完全両立
本作では、プレイスタイルに応じた2大防衛アプローチの双方が正解となるゲームデザインを確立する：

```
【防衛力型】 高🛡️ ✕ 低〜中連携 ➔ 安定・低リスク（一地点集中で圧殺）
【地形戦型】 低〜中🛡️ ✕ 高連携 ✕ 地勢活用 ➔ 高効率・高リスク（知略で大軍を捌く）
```

- **防衛力型（安定・重装型）**:
  - 特徴：高い 🛡️ を集中的に投入し、確実な力押しで防衛する。多方面侵攻には弱いが、情報不足でも破綻しにくい。
- **地形戦型（知略・機動型）**:
  - 特徴：湿原、森林帯、丘陵、隘路、街道誘導、騎馬軍、予備隊を駆使。少ない 🛡️ で敵の制圧力を削り取る。
  - **目標体験**: 「制圧力 38 の大軍を、わずか 🛡️ 14 で見事に止めた」という知恵による大逆転劇を成立させる。

## 🎯 9. 迎撃地点選定 ＆ 迎撃処理プロセス

### 1. 迎撃しないルートの盤面自然減衰
迎撃枠（連携）が足りず、人類部隊を配置しなかった方面であっても、盤面上の国土は敵軍へ作用する。
- 例：侵入 ➔ 森林 ➔ 湿原 ➔ 丘陵 ➔ HQ と敵が進軍する場合、人類部隊が不在でも、森林の遅延、湿原の泥濘減衰、丘陵の抵抗等により、敵制圧力は自然減衰する。
- プレイヤーは「北方は森林と湿原の自然減衰に任せ、主力を東方へ集中する」といった地勢的割り切りを行うことができる。

### 2. ルート上の迎撃地点選択
プレイヤーは迎撃する方面を決めた後、**「その進軍ルート上のどこで迎え撃つか」**を選択する。
- 侵入口直後の平地で早期迎撃するか。
- 森林を抜けさせ、疲弊したところを湿原へ引き込んで叩くか。
- 本営手前の丘陵に陣を敷き、決戦を挑むか。

### 3. 迎撃処理（成功/失敗の二値判定からの脱却）
戦闘は単純な勝敗（全滅か無傷か）ではなく、**残存制圧力の逐次進軍**として処理される。

```
敵制圧力 20 ➔ 迎撃による削減 15 ➔ 敵残存制圧力 5
```

- 削り切れなかった残存敵軍（制圧力 5）は、そのまま本営に向けて進軍を継続する。
- 後続の地形減衰、第2迎撃地点、特殊ブロック、試練中の介入カードによってさらに削る多層防衛を行う。

## ⚡ 10. Trial中の限定的介入

試練は「事前に大戦略（布陣・配分・地点）を決定」し、進行中は **1〜3回程度の限定された重要介入** のみを行う構造とする（※RTSのような連続操作・リアルタイムアクションにはしない）。

- **主な介入候補**:
  - 予備隊の緊急再配置
  - 騎馬軍の突進・増援
  - 夜襲戦術の発動
  - 迎撃地点の緊急後退・変更
  - 焦土退却
  - 伏兵の起動

## 🔥 11. HQ到達 ＆ 🔥損失 ＆ リザルト評価

### 1. HQ到達時の直接 🔥 損失
- **旧仕様の「本営への直接攻撃処理なし」を完全に廃止**する。
- 迎撃や地形で削り切れず、敵制圧力が残ったまま本営 (HQ) に到達した場合、**残存制圧力に応じて直接的な 🔥（命の残量）の損失が発生する**。
- *(※残存制圧力から 🔥 損失への具体的な変換式・帯域テーブルはプロトタイプ調整予定)*

### 2. 多角的な試練結果（リザルト）判定
- 試練の最終評価は、旧来の「敵全体の削り率 (%)」のみを基準とする単純判定を廃止する。
- **評価参照要素**:
  - HQへ到達してしまった敵残存制圧力
  - 守り切った侵攻ルート数
  - 突破を許したルート数
  - 実際に被った 🔥 損失
  - 国土・タイルの荒廃損害
  - 防衛施設・特殊ブロックの損傷
- ※現行の S〜D ランク基準数値は、上記新仕様に合わせた再調整前提の「暫定値」として位置付ける。

## 📜 12. 情勢・諜報 (04) との接続 ＆ 未確定事項一覧

### 1. 情勢・諜報カテゴリとの接続（情報解像度の推移）
試練予告（例: 試練襲来の 5 ターン前）以降、ターン経過や諜報活動によって敵情の「情報解像度」が段階的に向上する：

```
T-5: 「東方に大規模な軍勢の兆候」
T-4: 「北方に別働隊を確認」
T-3: 「亜人司令官は東方主力に帯同」
T-2: 「東方の戦力は全体の約4割と判明」
T-1: 「南方は陽動の小規模部隊と確定」
```

- 諜報システムは「嘘情報に惑わされる」のではなく、**「初期は解像度が粗く、投資やカードによって解像度が高まる」**という情報勾配として機能する。

### 2. 今回確定しない事項（方向性確定 / 数値未確定一覧）
以下の項目は設計の方向性のみを確定し、具体数値および詳細パラメータは今後のプロトタイプ・テストプレイにて決定する：

- 盤面産出帯（Tier）から敵制圧力への具体的な繁栄補正計算式
- 各Trial（第1・第2・第3）の基礎制圧力ベース値
- 連携による迎撃枠追加の最終閾値および最大枠数
