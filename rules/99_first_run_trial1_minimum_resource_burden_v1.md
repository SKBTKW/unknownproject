# FirstRun Trial1 最低80%リソース消費（暫定・2026-10-03）

ユーザー指示：初見プレイで最低8割消費するバランスに調整。
微調整、被害量・生存・復興の総合バランスは別途検討する。

## 現行契約

- 対象：FirstRunのTrial1、単一迎撃。通常Run・Trial2以降・明示的host policyは変更しない。
- 分母：配備Commit直前の🌾・🧱所持量。それぞれ独立に最低80%消費する。
- 平時のカード・盤面投資支出を80%達成分に算入しない。
- 暫定消費率：80% + 8% × 配備🛡️ / 使用可能🛡️ + 2% × min(距離 / 4, 1)。最大90%。
- 🌾の追加負担11ポイントを廃止。両リソースに同じ基本消費率を適用。
- 🌾保護は最大35、所持量の10%まで。整数丸め後もceil(所持量 × 80%)を下回らない。
- 所持量0は消費0。資源不足を偽装して支払わせず、既存atomic paymentとstale再検証を維持。
- 配備率・距離の違いは80–90%内の費用差として維持する。
- 🌾150 / 🧱150・全配備・距離4なら🌾135 / 🧱135支払い、各15残存。
- 費用は既存配備Commitで一度支払う。Settlementで追加の一律徴収を行わない。

## 認証基準の更新理由

旧Trial1 PVE 4.50–6.80 / 5.00–7.60節は無制限備蓄下の歴史的authoring reference。
保持上限150と今回の最低80%指示では、所持量と産出の比が変わる。
歴史的PVEは観測・報告を続けるが、現行Trial費用の合否は実際のStage1 seedごとの
🌾・🧱消費率80%以上、支払可能性、純粋Preview、atomic Commit、stale拒否で認証する。
旧「平時投資を含む70–80%」の上限判定は今回のユーザー指示で置き換える。
