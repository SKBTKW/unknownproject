# 03. 土地システム (Land System) 確定仕様

## 🧮 1. 1マス基礎産出公式 ＆ 13パターン確定数値マトリクス

すべての土地の毎ターン基礎産出量は、以下の統一数学公式から機械的に算出されます。

$$\text{基礎産出} = (\text{GL補正値} + \text{H補正値}) \times \text{マス数}$$

*(※★ボーナス資源ソケットや王都圏加算、政体バフなどのボーナス加算は別項独立処理)*

#### 🏰 2. 拠点 (Outpost) の発生 ＆ 今後の発展拡張仕様

- **【拠点の解禁 3 重条件】**:
  - 『一定数8マス以上のグリッド配置』✕『🔥12以上の生命力余力』✕『🧱25 / 🌾40 以上の経済蓄積』の 3 重条件が揃った時、拠点の建築が可能となる。
- **初拠点配置時**:
  - 初回配置時の特化先（3大性格: 防衛/経済/祭祀）の指定は一旦なし（標準の拠点として配置）。
- **城市 (Castle-City) への昇格条件**:
  - 将来的な発展要素として一旦保留。
- **拠点コスト漸増**:
  - 拠点を建設するごとに、必要コストが段階的に増加する（第1拠点: 🧱25 ➔ 第2拠点: 🧱50 ➔ 第3拠点: 🧱100）。

## 🗺️ 1. 土地ブロックの『配置』 ＆ 『開拓』の定義・コアルール

- **【操作 ＝ 『配置』 ✕ 成果 ＝ 『開拓』 の定義】**:
  - 手札の土地ブロックを盤面上へ置く操作を **『配置 (Placement)』** と呼び、配置によって領土・生存圏（版図）を広げる成果を **『開拓 (Pioneering / 開拓度)』** と定義する。
  - **UI・案内文章文体**: **`「土地ブロックを盤面へ配置し、領土を開拓しよう」`**
- **本営隣接ルール (第一歩の配置)**:
  - 最初の1マス目は本営に隣接するマスへ『配置』を行う。（※ささやかな第一歩ボーナスが発動）。
- **土地連続ルール**:
  - 2マス目以降の『配置』は、本営または配置済みの土地に途切れることなく連続して隣接している必要がある。

## 🏔️ 2. 地質高度階層 (Elevation 1〜3) ＆ 隣接高度物理制約

- **高度 1 (平地 / 低地)**: インフラ・農耕展開の中心 (`防衛倍率 1.0x`)
- **高度 2 (丘陵 / 高地)**: ⛏️鉱脈・資材 🧱 の主産出地 (`防衛倍率 1.5x` / 高所バフ)
- **高度 3 (山岳 / 最高峰)**: 🛡️防衛力特化・要塞拠点 (`防衛倍率 2.0x` / 高所防衛大バフ)
- **「隣接高度差 ≦ 1」物理制約**:
  - ブロック内および盤面上の隣り合う任意の2マスの高度差は常に `1` 以下 (`|高度A - 高度B| ≦ 1`)。
  - `1 ➔ 3` の垂直な絶壁配置は不可。必ず `1 ➔ 2 ➔ 3` のなだらかな傾斜グラデーションを保持。
- **🚫 山岳による本営全方位包囲禁止 (馬謖ガード)**:
  - 山岳（H3）によって本営が全方位完全に囲まれ、補給線・水脈が分断される配置はシステム的に禁止ガードされる。

## 🧩 3. 同属性 2×2 任意連結 (マージ ＆ 再生成) システム

- **2×2 マージ解禁**:
  - 同属性（H ✕ GL）の土地が 2×2（4マス正方形）に揃った際、プレイヤーの任意で **「1つの新たな2×2大型土地ブロック」へ合体・再生成（マージ）** 実行可能。
- **【絶対マージ不可ルール】**:
  1. 🏰 **本営周囲8マス (王都圏)**
  2. 🌟 **ボーナス資源 (★ソケット)** を含むブロック
- **マージ固定ボーナス**:
  - マージされた大型土地は、大領土としての固定産出ボーナスを獲得し、内政爆発の核となる。

---

## 🌊 3. 湖 (Lake / 湧水・清湖) のオアシス発見 ＆ 減衰・包囲自動認定

複雑な川（River）を廃止し、独立型水域 **『湖 (Lake)』** に単体一元化。湖は手札から任意配置できる土地ブロックではなく、**「★ ソケット（便宜上）の上へ『平地ブロック』を被せて配置・開花させた際、レア発見される特別な水源アセット（清湖/オアシス）」** と定義されます。

### 🌾 ① ソケット平地埋め開花 ＆ 階層減衰ルール
* **ソケット平地埋め限定**: ★ ソケットの上へ「平地ブロック」を被せて開花させた時のみ「湖 (Lake)」が確率で発見される。
* **1×1 ブロック優遇**: 小さく小回りの効く `1×1 平地` でソケットを埋めた時の方が湖の発見率が高く設定（`25%`）。
* **極大減衰アルゴリズム (ほぼ0だが絶対0ではない)**: 2個目以降の発見には極大減衰係数（`×0.04`）が適用され、確率 `0.2%` (数拾ランに1回の奇跡) へ移行する。
* **オマケプレビュー表示**: 画面上の文字説明は全廃し、「金の光粒きらめきビジュアル演出」のみで表現。カーソル横にドットアイコン1つ（🍎/🌾/⛏️/🌊）のおおよその見当付けプレビューを表示。そのラン内未発見のものは『？』表示。

### 🛡️ ② 湖の二重舞台効果 ＆ 包囲自動認定
* **内政舞台効果**: 湖の周囲 8 マスに **「水源の恵みバフ (+50% / 🌾+1)」** を付与。
* **防衛舞台効果**: 湖に隣接する迎撃地点では、敵が水際で足を取られる **「水際・泥濘（でいねい）減衰 (-30%)」** が発動。
* **1 周包囲自動 1 マス認定**: 本営周囲 8 マス（王都圏）に湖が発生した場合、システムが自動的に **「1 周包囲の 1 マス分（埋まり済み）」** と認定し、パズルが詰まない。

## 🌟 4. ★ ソケット (便宜上) の初期配置 ＆ 出現ルール
* **① 初期配置数 (5×5)**: ゲーム開始時、盤面上に **`確定 3 個`** のソケット（金の光粒きらめきマス）が配置される。
* **② 本営周囲 8 マスの絶対除外**: 本営の周囲 8 マス（王都圏）には、ソケットは **`100% 絶対に出現しない`**。（※1周包囲パズルを保護）
* **③ 2 連結以上なし (完全孤立配置)**: ソケット同士が上下左右に隣接（2連結以上）して発生することは物理的に禁止。必ず孤立点在する。
* **④ マップ拡張時の追加生成**: Stage 2 (7×7) 拡張時に **`追加 3 個`**、Stage 3 (9×9) 拡張時に **`追加 4 個`** が新領域に自動生成される。

## 🌾 5. 大○○系 2×2 マージ土地ブロック (大草原 / 大森林 / 大丘陵 / 大山脈)
同属性（H ✕ GL）の土地が 2×2（4マス正方形）に揃った際、プレイヤーの任意で合体・再生成（マージ）される大型土地ブロック。

* **確定ネーミング**:
  * 🌾 草原 2×2 ➔ **『大草原』**
  * 🌲 森 2×2 ➔ **『大森林』**
  * ⛰️ 丘陵 2×2 ➔ **『大丘陵』**
  * 🏔️ 山岳 2×2 ➔ **『大山脈』**
* **4 大制限ルール**:
  1. **再合体不可**: 一度『大○○』となったブロックは、二度と他のブロックと再合体できない。
  2. **王都圏マージ禁止**: 本営周囲 8 マスにかかる土地はマージ実行不可。
  3. **ソケット巻き込み禁止**: 未開花ソケットを含む 4 マスエリアはマージ実行不可。
  4. **同種上限制限**: 1 盤面につき同種『大○○』は最大 2 〜 3 個まで。
