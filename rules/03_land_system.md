# 03. 土地システム (Land System) 確定仕様

## 🧮 1. 1マス基礎産出公式 ＆ 13パターン確定数値マトリクス

すべての土地の毎ターン基礎産出量は、以下の統一数学公式から機械的に算出されます。

$$\text{基礎産出} = (\text{GL補正値} + \text{H補正値}) \times \text{マス数}$$

*(※★ボーナス資源ソケットや王都圏加算、政体バフなどのボーナス加算は別項独立処理)*

## 🏔️ 2. 地質高度階層 (Elevation 1〜3) ＆ 隣接高度物理制約

- **高度 1 (平地 / 低地)**: インフラ・農耕展開の中心 (`防衛倍率 1.0x`)
- **高度 2 (丘陵 / 高地)**: ⛏️鉱脈・資材 🧱 の主産出地 (`防衛倍率 1.5x` / 高所バフ)
- **高度 3 (山岳 / 最高峰)**: 🛡️防衛力特化・要塞拠点 (`防衛倍率 2.0x` / 高所防衛大バフ)
- **「隣接高度差 ≦ 1」物理制約**:
  - ブロック内および盤面上の隣り合う任意の2マスの高度差は常に `1` 以下 (`|高度A - 高度B| ≦ 1`)。
  - `1 ➔ 3` の垂直な絶壁配置は不可。必ず `1 ➔ 2 ➔ 3` のなだらかな傾斜グラデーションを保持。
- **🚫 山岳による本営全方位包囲禁止 (馬謖ガード)**:
  - 山岳（H3）によって本営が全方位完全に囲まれ、補給線・水脈が分断される配置はシステム的に禁止ガードされる。

## 🧩 3. 同属性 2×2 任意連結 (マージ ＆ 再生成) システム

- **2×2 マージ解禁**:
  - 同属性（H ✕ GL）の土地が 2×2（4マス正方形）に揃った際、プレイヤーの任意で **「1つの新たな2×2大型土地ブロック」へ合体・再生成（マージ）** 実行可能。
- **【絶対マージ不可ルール】**:
  1. 🏰 **本営周囲8マス (王都圏)**
  2. 🌟 **ボーナス資源 (★ソケット)** を含むブロック
- **マージ固定ボーナス**:
  - マージされた大型土地は、大領土としての固定産出ボーナスを獲得し、内政爆発の核となる。

## 🌊 3. 川 (水脈/水源) の現実的な『自然舞台効果』

川は「初心者救済メカニクス」ではありません。現実の自然や古代文明における **「水脈・水源のありよう」** をリアルかつ直感的に反映した **【自然の舞台効果 (Environmental Stage Effect)】** です。プレイヤーが地形を巧みに活かすことで、内政と防衛の双方で大きなストラテジーの楽しさを生み出します。

### 🌾 ① 内政舞台効果: 水源による周辺地形への恵みバフ
* **恵みの水脈**:
  * 川（水脈）に隣接する土地（`草原 GL1` や `森林 GL2`）は、豊かな水源の恵みを受け、**食料 (`🌾`) や資源の産出量が強化 (`+50%` / 🌾+1)** される。
  * 古大文明がナイル川や大河の流域で繁栄したのと同様に、**「川沿いに集落や農耕地を広げるのが直感的に最も豊かになる」** という自然な手触りと楽しさを提供します。

### 🛡️ ② 試練・戦闘舞台効果: 現実の渡河戦における影響
* **渡河ペナルティ (渡河攻撃デバフ)**:
  * 敵軍が渡河して侵攻してくる際、足を取られ隊列が乱れる現実の渡河戦を再現。
  * 彼我の間に「川」が介在する迎撃地点を指定した場合、**敵の制圧力が確定で `-50%` 減衰** する。
* **ストラテジーの楽しさ**:
  * 安易な初心者救済ではなく、**「川という自然の地形を巧みに利用して完璧な渡河防衛ラインを構築する」** という、直感的で知的な地政学パズルの楽しさを生み出します。軌跡・延伸制御アルゴリズムについては、今後の開発において要検討事項とする。
