## 🔥 2. 残り火 (Ember) ＆ 食料蓄積連動ルール

`🔥 残り火` は命運を示す生命線リソースです（初期値想定: 🔥10〜15 / 最大上限なし）。

### 2.1. 🌾 食料維持費 ＆ 🔥 3段階状態連動ステッピング
食料維持費は毎ターンの複雑な数式計算ではなく、**🔥の3段階状態（危機 / 標準 / 旺盛）に連動して段階的に切り替わります**。

- **🔥 9 以下 (微火・危機)**:
  - 画面暗転・視界縮小演出
  - **`🌾 食料 15/T`** (※産出デバフなし。維持コスト減圧による省エネ復興の道)
- **🔥 10 〜 23 (標準状態)**:
  - 通常状態 / **`🌾 食料 20/T`** (基本維持費)
- **🔥 24 以上 (旺盛状態)**:
  - 全リソース産出 `+10%` ブースト / 毎ターン `✨+2` 自動ボーナス
  - **`🌾 食料 25/T`** (火が大きいので維持費増)

### 2.2. 🌾 食料蓄積量による 🔥 自動自家発生ルール
毎ターンの `🌾 食料` 蓄積量に応じて、毎ターンの `🔥` 減衰・回復が動的変化します。

- **`🌾 食料 200 未満`**: **`-1 🔥 / ターン`** (標準燃焼減衰)
- **`🌾 食料 200 以上`**: **` 0 🔥 / ターン`** (**燃焼減衰ストップ！無消費**保持)
- **`🌾 食料 500 以上`**: **`+1 🔥 / ターン`** (**自家発熱！毎ターン自動回復**)

## 🛡️ 4. 防衛力 (Shield / 🛡️) のリアルタイム総和算出 ✕ 非累積の原則【確定仕様】

防衛力 `🛡️` は、過去ターンに蓄積されていくストック型リソース（`🌾/🧱/✨`）とは異なり、**現在の盤面状態（Board State）に基づく非累積のリアルタイム数値** として定義される。

### 4.1. 🧮 防衛力 `🛡️` の確定算出公式
$$\text{場の現在合計防衛力 } 🛡️ = \sum (\text{盤面上に現在実在する全土地ブロックの } 🛡️) + \text{本営単体防衛力 } 🛡️ (10)$$

- **非累積の原則 (No Accumulation)**:
  - `🛡️` は毎ターン累積加算（蓄積）されるリソースではなく、**「現在その瞬間に盤面上に配置・実在している土地および拠点のリアルタイム合計数値」** のみを参照する。
- **試練での摩耗 ＆ 修復連動**:
  - 試練で土地や拠点が摩耗（損害）を受けた場合、盤面の `🛡️` 合計数値はリアルタイムで減少する。
  - 試練後に `🌾/🧱` を消費して任意全回復修復させた際、本来の `🛡️` 合計数値へ即座に復帰する。
