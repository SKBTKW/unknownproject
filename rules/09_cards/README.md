# 09. カード一覧 仕様書 (Card List Specification - Master Index)

本仕様書は、全カードマスターデータベースおよび確定カード定義の **親ポータル・目次（インデックス）仕様書** である。
実データおよび詳細定義は、本フォルダ (`rules/09_cards/`) 配下の4つのカテゴリ別仕様書に分類・管理されている。

---

## ─── 📚 カテゴリ別仕様書 目次 ───

カードの追加、効果パラメータ・数値の直接編集、詳細なドロー提示条件の閲覧は、各カテゴリの個別仕様書を参照すること。

### 1. 🌱 [01. 土地カード仕様書 (01_land_cards.md)](./01_land_cards.md)
* **対象**: 全7群の土地カード (平地, 森, 深い森, 丘陵, 山岳, 砂漠, 複合土地)
* **概要**: 領土を開墾し、毎ターンの基礎持続収入（🌾食料 / 🧱資材 / 🛡️防衛 / ✨神秘）を生み出すインフラカード群。

### 2. 📜 [02. 経済・政策カード仕様書 (02_economy_cards.md)](./02_economy_cards.md)
* **対象**: `CMD_AGRICULTURAL_POLICY` (治水農具), `CMD_BLACK_MARKET` (闇市場), `CMD_LAND_FOCUS` (土地探索重視)
* **概要**: 食料(`🌾`)や資材を一括消費し、資材獲得・農地改善・土地ドロー偏向をもたらす使い切りコマンド群。

### 3. 🛡️ [03. 軍事・防衛カード仕様書 (03_military_cards.md)](./03_military_cards.md)
* **対象**: `CMD_IRON_RAMPART` (鉄壁の防壁), `CMD_BALLISTA_SET` (迎撃用弩砲), `CMD_MILITARY_FOCUS` (軍事重視)
* **概要**: 資材(`🧱`)を一括消費し、グローバル防衛力(`🛡️`)や試練の被害無効化、軍事ドロー偏向をもたらすサバイバルコマンド群。

### 4. ✨ [04. 神秘・奇跡カード仕様書 (04_mystic_cards.md)](./04_mystic_cards.md)
* **対象**: `CMD_REKINDLE_EMBER` (聖なる再燃), `CMD_TRANSMUTE_GOLDEN` (黄金秘境変容), `CMD_MYSTIC_FOCUS` (神秘重視)
* **概要**: 神秘(`✨`)や残り火(🔥)を一括消費し、残り火回復・聖なる光脈変容・神秘ドロー偏向を起こす超常現象コマンド群。

## ──────── 📌 既存仕様との変更点・差分一覧 ────────

| 対象項目 | 既存の仕様 | 今回の変更・追加仕様 | 変更の理由・背景 |
| :--- | :--- | :--- | :--- |
| **カテゴリ構成** | 1ファイル全包含（5カテゴリ） | **4大カテゴリ（土地 / 経済 / 軍事 / 神秘）へ分割サブフォルダ化** | メンテナンス性・直感的な視認性向上および旧カテゴリ5の除外 |
| **新カラム追加** | なし（5列〜7列構造） | **「ドロー提示条件」「簡潔な効果」の2列を全テーブルに追加** | 毎ターンの動的ドロー条件とカード効果の視認性向上 |
| **深い森 (1×2)** | Stage 1 解禁 (R) | **`Stage 2` 解禁** へ変更 | Stage 1 のチュートリアル保護（1×1 単体のみ約3%希少解禁） |
| **砂漠 (1×2)** | Stage 1 解禁 (UR) | **`Stage 2` 解禁** へ変更 | Stage 1 のチュートリアル保護（1×1 単体のみ約3%希少解禁） |
| **複合土地 (1×2全種)**| Stage 1 解禁 | **`Stage 2` 解禁** へ変更 | 砂漠丘陵・森丘陵・森林丘陵を Stage 2 のアンロック報酬化 |
| **1×3 マスカード全種** | レアリティ `UC` (アンコモン) | レアリティ **`R` (レア)** に統一設定 | 1×3 マスカード全体の Stage 2 合算出現率を 約8.0% に調整 |
