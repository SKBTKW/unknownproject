# 02. 土地特性付与

## 概要
場の土地からボーナス資源を発見するカテゴリ。

## ボーナス資源一覧 ＆ 発現条件 (確定版)

未開拓マスに存在する「✨ボーナスソケット」に適合する土地ブロックをハメ込むことで、以下のボーナス資源がアンロック・発動します。

| ボーナス資源 | 主な効果 | 発現条件（地形 ✕ GLレベル） | レアリティ |
|--------------|----------|----------------------|----------------|
| **果実**     | **`🌾 +10`** | **平地・丘陵・森林・砂漠 (高度1〜2, GL0〜3)** (※砂漠はデーツ/ナツメヤシ) | C (Common)     |
| **穀物**     | **`🌾 +15`** | 開拓平野 (高度1, GL1) | C (Common)     |
| **家畜**     | **`🌾 +15`** | 草原丘陵・平野 (高度1〜2, GL1) | C (Common) |
| **高級木材** | **`🧱 +20`** | 森林平地・丘陵 (高度1〜2, GL2〜3) | UC (Uncommon) |
| **鉱脈**     | **`🧱 +15`** | 丘陵・山岳 (高度2〜3) | UC (Uncommon)  |
| **貴金属**   | **`🧱 +10 / ✨ +5`** | 丘陵・山岳 (高度2〜3) | R (Rare) |
| **水産物**   | **`🌾 +15`** | 川沿いマス・水域 (高度0〜1) | C (Common) |

## ★ ボーナス資源ソケット ＆ 開拓者【地質測量】メカニクス

1. **✨ ソケット視認**: 未開拓地にほのかな光の波紋（✨）が事前浮遊。
2. **ハメ込みアンロック**: 適合する土地ブロックを重ね合わせると、上記ボーナス資源がアンロックされ産出に加算！
3. **🪓 開拓者 (Pioneer) 特権【地質測量】**: 未開拓地のソケットの中身（🍎果実/⛏️鉱脈/🏜️オアシス等）を事前解明！


## 優先度
高

## 場の影響
非常に受けやすい

## 関連設計思想
場の土地状況が次のドローの傾向を決める。

## 特別イベント: 川の発見

** 発生条件 **: 場に川が1枚もない場合のみ発生可能（レアイベント）

** イベントの流れ **
1. **発見**  
   - 川特性付きの土地を**確定で一1枚**発見（場に出すかは任意）

2. **下流探索の継続**（最大3回）  
   - 各回で食料と資材を消費して探索隊を援助
   - **高額援助**なら確定で継続
   - **中額援助**なら低確率で継続
   - **援助なし**なら高確率で失敗

3. **3回成功時**  
   - レジェンダリー地形「海」に到達する可能性あり
