# 02. 土地特性付与

## 概要
場の土地からボーナス資源を発見するカテゴリ。

## 現在のボーナス資源一覧（暫定）

| ボーナス資源 | 主な効果 | 付与条件（主なもの） | レアリティ目安 |
|--------------|----------|----------------------|----------------|
| **果実**     | 🌾 +10〜15 | 平地、森       | C        |
| **穀物**     | 🌾 +15     | 平地                 | C         |
| **家畜**     | 🌾 +15     | 平地                 | C         |
| **鉱脈**     | 🧱 +15     | 丘陵、山岳           | UC     |
| **貴金属**   | 🧱 +10 / ✨ +5 | 丘陵、山岳         | R           |
| **高級木材** | 🧱 +20     | 森                   | UC     |
| **水産物**   | 🌾 +15     | 川・水源              | C     |


## 優先度
高

## 場の影響
非常に受けやすい

## 関連設計思想
場の土地状況が次のドローの傾向を決める。

## 特別イベント: 川の発見

** 発生条件 **: 場に川が1枚もない場合のみ発生可能（レアイベント）

** イベントの流れ **
1. **発見**  
   - 川特性付きの土地を**確定で一1枚**発見（場に出すかは任意）

2. **下流探索の継続**（最大3回）  
   - 各回で食料と資材を消費して探索隊を援助
   - **高額援助**なら確定で継続
   - **中額援助**なら低確率で継続
   - **援助なし**なら高確率で失敗

3. **3回成功時**  
   - レジェンダリー地形「海」に到達する可能性あり
