# 02. 拠点 (Outpost) 確定仕様書

## 🏰 1. 拠点 (Outpost) の建設 ＆ 4 大判定条件

- **正式解禁タイミング**: **`第 1 試練突破後 (Stage 2: 7×7 盤面拡大時)`** に拠点建設が正式解禁される。
- **建設可能地点の 4 大判定条件**:
  1. **本営離隔条件**: 本営から **`3 マス以上離れている`** こと（※本営との間に最低 2 マスの空間を空け、本営から数えて 3 マス目以降の未配置マスにのみ建設可能）。
  2. **未配置グリッド条件**: **`未配置の空きマス`** であること。
  3. **土地隣接条件**: 配置済みの土地ブロックに **`1 面以上隣接している`** こと（※完全孤立の飛び地建設を防止）。
  4. **山岳非隣接条件**: **`H3 山岳に隣接していない`** こと（※防衛拠点を含む全拠点共通）。
- **前線ハブ機能**: 拠点が建設された未配置マスは **`第 2 の開拓基点`** となり、次ターン以降その拠点の周囲（未配置エリア）へ新たな土地ブロックを配置・接続して領土を拡大できる。
- **🏰 3×3 拠点圏 (Outpost Zone) 開発 ＆ コンプリートメカニクス**:
  - **省スペース建設**: 拠点本体は **`1×1 マス`** へ建設。
  - **3×3 拠点圏の有効化**: 建設された瞬間、拠点本体を中心とする **周囲 8 マス（3×3エリア）が「拠点圏 (Outpost Zone)」として指定・有効化** される。
  - **拠点圏配置ボーナス**: 拠点圏内の周囲 8 マスに土地が配置されると、基礎産出への加算ボーナス (`+1 / マス`) や開拓ハブ効果が発動。
  - **【前線要塞コンプリートボーナス】**: 拠点圏の周囲 8 マスがすべて土地で埋め尽くされると「前線要塞完成！」のアナウンスとともに、拠点防衛力が **`🛡️+10`** 永久強化 ＋ **`🔥+3`** 即時回復！
- **建設コスト**: 第 1 拠点 `🧱 25` ➔ 第 2 拠点 `🧱 50` ➔ 第 3 拠点 `🧱 100` (漸増)。

## 🏛️ 2. 拠点 ➔ 城市 (Castle-City) への段階的発展 ＆ 3 大性格選択

- **レベル 1 (初期設置)**: 「拠点 (Outpost)」。
- **レベル 2 (完成昇格)**: 本営からの街道完全接続 ＆ 資材 `🧱` 投下により城郭都市「城市 (Castle-City)」へ昇格。その際、以下の 3 大性格タイプから 1 つを選択・特化。
  - **🛡️ 1. 防衛拠点 (Military Fort)**: 周囲 3×3 拠点圏内の `🛡️ 防衛力` 大バフ ✕ 試練時地形戦術強化。
  - **🌾 2. 経済拠点 (Economic Hub)**: 周囲 3×3 拠点圏内の `🌾 食料` / `🧱 資材` 産出大バフ ✕ 補給線ボーナス強化。
  - **✨ 3. 祭祀拠点 (Sacred Sanctuary)**: 周囲 3×3 拠点圏内の `✨ 神秘` 産出大バフ ✕ `🔥 残り火` 自家発電効率アップ。
- **タイプ変更禁止**: 一度選択した拠点タイプは後から変更・切り替え不可。
- **本営周囲の山岳制限**: 本営周囲 8 マス（3×3 王都圏）内は H3 山岳の配置不可。
- **制約**: 1 ランにつき各タイプ最大 1 つまで（重複禁止 / ユニーク建築）。スキルツリーによる拠点強化は対象タイプへ自動一括適用。

- **建設コスト ✕ 保有グリッド数スケーリング (重厚設計 ✕ 3個上限)**:
  - **第 1 拠点**: `🧱 60` ＋ `🔥 3` 消費 / 必要保有土地 `12 マス` 以上 (Stage 2 で 1 個目解禁)
  - **第 2 拠点**: `🧱 120` ＋ `🔥 5` 消費 / 必要保有土地 `24 マス` 以上 (Stage 3 で 2 個目解禁)
  - **第 3 拠点**: `🧱 240` ＋ `🔥 8` 消費 / 必要保有土地 `40 マス` 以上 (Stage 3 で 3 個目解禁)
  - **全ラン絶対上限枠**: **【最大 3 個まで】** (4方角に対し3個制限とすることで地政学的ジレンマを発生させる)。
- **1 拠点 1 方角限定ルール (ダブルカバー全廃)**:
  - 四隅等の特権判定は全廃し、拠点はその位置するエリアの 【1 方角のみ (北・東・南・西のいずれか)】 の軍事視界（6T前進軍ルート可視化）を提供する。盤面拡大 (5×5 ➔ 7×7 ➔ 9×9) 時も一切のルール不整合を起こさない。
- **建設判定条件 5 (保有グリッド数条件)**: 無計画な飛び込み建設を防止するため、一定数以上の開拓済み土地グリッドを保有していることを必須条件とする。
