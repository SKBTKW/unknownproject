# 04. レジェンダリ土地

このファイルでは、通常の土地とは異なる特別な地形（レジェンダリ土地）について記載する。
- 全て場のスロットを2つ消費する
伝説級地形は通常の土地を遥かに超える強力な効果を持つ特別な地形です。  
出現条件が厳しく、ゲーム後半の戦略的分岐点となります。

## 大森林（Great Forest）
- **出現条件**: 緑の深さ4以上が複数接続 + 神秘一定量
- **基本出力**: 🌾+30 / 🧱+15 / 🛡️+15 / ✨+10
- **特性**:
  - 周辺土地の緑の深さを+1（最大5）
  - 食料生産ボーナスが広範囲に波及
  - 神秘関連カード出現率アップ
- **備考**: 人類が失った「原初の楽園」の残滓。開発すると強力だが、試練で「自然の怒り」が発生しやすい。

## 大砂漠（Great Desert）
- **出現条件**: 砂漠（緑の深さ1）が複数接続 + 神秘高
- **基本出力**: 🌾-10 / 🧱+10 / 🛡️+5 / ✨+25
- **特性**:
  - 神秘の大量産出
  - 古代遺跡・レリック発見率大幅アップ
  - 砂嵐を味方につける軍事ボーナス
- **備考**: 「忘れられた神々の墓場」。預言者ロールで真価を発揮するが、水源管理を誤ると壊滅的。

## 大渓谷（Great Canyon）
- **出現条件**: 山岳 + 丘陵が隣接 + 特定の試練経験後
- **基本出力**: 🌾+5 / 🧱+30 / 🛡️+25 / ✨+8
- **特性**:
  - 強力な防衛力（要塞効果）
  - 資材産出特化
  - 隠れ里・要塞建設に適した地形ボーナス
- **備考**: 「大地の傷跡」。天然の要害として将軍ロールに強いが、移動・開発に制約あり。

## 大湖（Great Lake）
- **出現条件**: 湖が複数接続 + 水源特性強化
- **基本出力**: 🌾+25 / 🧱+5 / 🛡️+15 / ✨+12
- **特性**:
  - 水源の強化版（周辺土地に強力な食料・灌漑ボーナス）
  - 水産資源の大量産出
  - 舟運・交易ルートボーナス
- **備考**: 「最後の命の源」。開発不可だが、周辺土地全体を豊かにする強力な支援地形。

## 海 (Sea)

**位置づけ**  
人類が世界の片隅で生き延びる中で、初めて到達した「未知の果て」。  
長い探索と投資の末に手に入れる、圧倒的なロマンと力を秘めた特別な存在。

**取得タイミング**  
- 最速：35ターン目以降  
- 現実的な取得タイミング：37〜42ターン目  
- 川探索イベント発生後、最低12〜15ターンの過程が必要

**性能の方向性**  
- かなり強力な産出と特殊効果を持つ    
- 恩恵を受ける期間が長くない（取得が遅いため）

**設計思想**  
- 人類が初めて到達する「未知の果て」としてのロマン  
- 長い焦らしの末に手に入れる達成感  
- 次のプレイでも「また海が欲しい」と思わせる欲求の残し方
