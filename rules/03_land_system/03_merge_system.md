> プレイヤー向けには、旧 `MERGE` を状態名では「地帯」、成立処理では「地帯化」と呼び、旧 `LINK` を「連携」と呼ぶ。内部実装・セーブ互換用の `merge*` / `mergeLinks` は旧名称のまま維持する。

## 🌾 1. 4マス地帯の成立形状（最新確定仕様）

地帯化は**「全地形共通の2×2正方形」**と**「丘陵・山岳限定の異形」**の2段階構造で適用される。

### 1. 【全地形共通】2×2正方形の地帯化
すべての地形（平地 / 丘陵 / 山岳）において、同属性の土地4マスが2×2正方形にまとまった際に地帯が成立する。

```
■ ■
■ ■
```

#### 🎯 2×2正方形の地帯成立時ボーナス
2×2正方形の地帯が成立した瞬間、共通祝儀 **`🔥 +1`** に加え、地形属性に応じた以下の即時ボーナスが一括給付される：

* 🌾 **平地 (`GL1`) 2×2**: **`🔥 +2` ＋ `🌾 食料 +10`** (※開拓祝儀ボーナス)
* 🧱 **丘陵 (`E2`) 2×2**: **`🔥 +1` ＋ `🧱 資材 +8` ＋ `🌾 食料 +4`**
* 🛡️ **山岳 (`E3`) 2×2**: **`🔥 +1` ＋ `🧱 資材 +10` ＋ `✨ 神秘 +5`**

---

### 2. 【丘陵・山岳限定】異形地帯（L字型 / 凸字型）
丘陵および山岳を特定の**異形パターン**（4マス）で開発した場合、即時ボーナス給付に加えて**「最後の1マスが★固有ソケットに覚醒」**し、さらに**「迎撃ポイント設定による特別戦術」**の対象ブロックとなる。
※防衛力（`🛡️`）は即時ボーナスでは直接給付されず、毎ターンの★覚醒ソケット・持続産出から得る設計。

#### 🧱 E2 丘陵：4マス構成 L字型 (1×3直線 ＋ 端1マス / 回転4パターン)
```
【パターン1】  ■         【パターン2】  ■ ■      【パターン3】  ■ ■ ■    【パターン4】    ■
              ■ ■ ■                   ■                          ■                  ■
                                       ■                                           ■ ■
```
* **成立時即時ボーナス**: **`🌾 食料 +4` ＋ `🧱 資材 +6` ＋ `🔥 残り火 +1`**
* **4マス持続産出**: **`合計 ✕ 1.2倍`**
* **最後の1マス覚醒**: 地帯化を完成させた最後の1マスが **『★ 隠匿鉱床 (Hidden Deposit)』** に覚醒 ➔ そのマス単体に **`🧱 +2/T, 🛡️ +1/T`** の永続ソケットボーナスが付与される。
* **迎撃ポイント戦術**: この地帯を迎撃ポイントに設定した場合、特別な伏兵戦術を発動可能。

#### 🛡️ E3 山岳：4マス構成 凸字型 (1×3直線 ＋ 中央1マス / 回転4パターン)
```
【パターン1】    ■       【パターン2】  ■        【パターン3】  ■ ■ ■    【パターン4】    ■
              ■ ■ ■                   ■ ■                      ■                 ■ ■
                                      ■                                           ■
```
* **成立時即時ボーナス**: **`🧱 資材 +8` ＋ `✨ 神秘 +4` ＋ `🔥 残り火 +1`**
* **4マス持続産出**: **`合計 ✕ 1.2倍`**
* **最後の1マス覚醒**: 地帯化を完成させた最後の1マスが **『★ 主峰砦 (Summit Fortress)』** に覚醒 ➔ そのマス単体に **`🛡️ +3/T, ✨ +2/T`** の永続ソケットボーナスが付与される。
* **迎撃ポイント戦術**: この地帯を迎撃ポイントに設定した場合、特別な籠城要塞戦術を発動可能。

## 📐 2. 地帯の産出計算と統合ルール

1. **1つの巨大ブロックへの生まれ変わり**:
   - 2×2正方形と同様、L字・凸字も地帯成立時に「1つの統合ブロック」として扱う。
2. **産出計算公式と報酬 (1.2倍増幅)**:
   - 地帯化条件を満たさず、単に1マスを4つ置いただけの場合は通常計算 `(GL+H)×4マス`。
   - 地帯化条件を達成した報酬として、地帯の持続産出に **`合計 ✕ 1.2倍`** の増幅ボーナスを与える。
   - 公式: `地帯持続産出 = (元となった4マスの合計産出 + ★ソケット持続産出) ✕ 1.2`

## 🔒 3. 地帯の隣接制限と探索ルール

1. **地帯の隣接制限（同属性2×2地帯の直接面隣接不可）**:
   - **地帯化していない単体ブロックの隣接は許可**: 成立済みの2×2地帯の隣に、同属性の単体ブロック（1〜3マス）を開発することは許可される（※置いても2×2地帯が成立しない場合）。
   - **新たな2×2地帯成立時の面隣接禁止**: 開発によって新たに2×2地帯が成立し、その地帯が既存の同属性2×2地帯と直接面隣接する場合は **開発不可（赤枠 ＆「同属性の2×2地帯同士は直接隣接できません」）** となる。
   - **異なる地帯の隣接は許可**: 異なる属性の地帯同士（例: 平地2×2地帯と丘陵2×2地帯）の面隣接は許可され、連携条件を満たす。

2. **本営近郊での地帯化を許可（ダブルシナジー）**:
   - 本営周囲8マス（3×3本営近郊）にかかる土地でも、条件を満たせば地帯化できる。
   - 地帯ボーナスの1.2倍増幅と本営近郊バフ (`+1/マス`) は重複適用される。

### 異属性地帯の連携（暫定プロトタイプ仕様）

- 異なる土地属性の成立済み4セル地帯同士が上下左右の辺で接触すると、連携が成立する。
- 1×2／1×3連結グループや地帯化していない土地は連携対象外とする。
- 同じ地帯ペアは接触辺数にかかわらず1連携とし、順序非依存のペアとして記録する。
- 新規連携1本につき、`🔥最大値 +1` を適用した後に `🔥現在値 +1` を即時付与する。
- 1回の開発で複数の連携が成立した場合は新規連携数分を加算し、同時成立そのものへの追加ボーナスは付与しない。
- Offering補正、資源流通、連携数による段階効果、連携専用盤面描画、その他の連携効果は今回の暫定実装には含めない。

### 地帯化済み土地の属性保護（暫定）

- 一度地帯化したセルは、伐採・干拓・火攻などによる恒久的なterrain／GL変更の対象外とする。
- 1×2／1×3連結グループは、この保護における地帯化済みセルには含めない。
- 一時的な産出補正やデバフは通常どおり適用する。

## 🎨 4. 地帯成立時の演出と専用グラフィック更新仕様

1. **ささやかで説得力のある結合演出 (ルール08準拠)**:
   - 4マスの地帯化条件が達成された瞬間、過剰で冗長な大爆発・派手な演出は一切行わず、**0.3秒間「境界線が光って吸い付くささやかなフラッシュ ＋ 気持ちよい結合音 (カチャッ/シュッ)」** を再生。
2. **専用一括グラフィックへの即時更新**:
   - 演出完了後、分割されていた 4 つの独立した1マススプライトが、**1枚の繋がった「専用結合グラフィック (例: 大草原 / 段丘連峰 / 主峰要衝)」** へシームレスに更新・置換される。

## 🌟 5. 周囲 8 マス包囲 ✕ 中央穴埋めボーナス 確定仕様

盤面上の未配置グリッド1マスの周囲8マス（3×3領域）を土地で完全に包囲し、最後の中央1マスを開発して埋めた瞬間に自動発動する。

### 1. 📐 開発適合ルール (高度・気候ギャップ準拠)
* **高度面**: 周囲が E1 (平地) の場合 ➔ `E1 (平地)` または `E2 (丘陵)` で開発可能 (※E3 山岳は不可)。
* **気候面**: 周囲が GL0 (砂漠) の場合 ➔ `GL0 (砂漠)` のみ開発可能。それ以外は `GL0 (砂漠)` 以外の気候土地で開発可能。

### 2. 🧮 状況に応じた 3 大ボーナス分岐詳細
1. **🌾 パターン A：通常マス中央穴埋め時**:
   - **恒常持続ボーナス**: 中央マスから毎ターン生成される **`✨ +10 / T`** の持続収入が確定付与される。
   - **穴埋め祝儀**: 即座に **`🔥 +2`** が即時回復する。
2. **🌴 パターン B：★ 資源ソケット中央穴埋め時 (砂漠埋め時)**:
   - **25% 確率発動 ➔ 『🌴 オアシス (Oasis)』 奇跡の昇華開花**:
     - **持続産出 (昇華置換)**: **`🌾 +3 / T` ＋ `✨ +5 / T`** （オアシス固有持続産出へ昇華）。
     - **開花祝儀**: 即座に **`🔥 +3`** 即時回復 ＋ ヤシの木と泉の専用オアシススプライト進化！
   - **75% 不発時 (通常ソケット開花)**:
     - 通常のソケット資源（デーツや硝石）が開花し、中央穴埋め恒常ボーナス **`✨ +10 / T`** が確定給付される。
3. **🏰 パターン C：全 9 マス完全同属性統一時 (3×3 完遂大結界昇華)**:
   - 周囲 8 マス＋中央 1 マスの「全 9 マス」が全て同じ属性（例: 全て平地 / 全て丘陵 / 全て山岳）で統一された場合、パターン A・B のボーナスに加えて **`全持続産出 1.3 倍 (+30%) 超増幅` ＋ `一枚絵 3×3 巨大都心スプライト進化` ＋ `黄金の光脈オーラ全開`** が発動する。

## ⚡ 6. 1×3 マスまでの同属性連結 段階的即時ボーナス（Instant Connection Bonus）確定仕様

4マスの「2×2 / L字 / 凸字地帯」へ至る手前の段階において、同属性・同高度の `1×1` 土地を盤面に並べて連結していく際、**段階的連結ルールおよび地帯化判定優先度に準拠した発動条件を満たした瞬間に即時獲得できるリソースボーナス（ワンタイム給付）**が発動する。

### 1. 確定・必要最小限ルール（3大原則）

1. **⚡ 1×2 連結即時ボーナス (80%切り捨て)**: 
   - **発動条件**: 同属性の土地で開発し、**「新たに 1×2（2マス連結）が成立した時」**に発動。（※連結ボーナス算出関数にて処理）
2. **🚀 1×3 連結即時ボーナス (150%繰り上げ)**: 
   - **発動条件**: 既存の 1×2 連結グループに対し、新たな 1マスが隣接して **「1×3（3マス連結：直線または L字）へ拡張された時」**に発動。（※連結ボーナス算出関数にて処理）
3. **⚠️ 4マス地帯ボーナス（最優先）**:
   - **発動条件**: 開発によって `2×2 正方形 / L字 / 凸字` の **地帯化条件が完成した時**に発動。（内部の地帯判定関数で処理）
   - **効果**: **`🔥 +1` 即時回復 ＋ 持続産出 1.2倍 ＋ 1つの合体大ブロックへ昇華**。（※1×2 や 1×3 の即時ボーナスより最優先）
