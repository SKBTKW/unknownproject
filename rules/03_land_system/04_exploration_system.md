# 04. 2D6 土地探索 確定詳細仕様書

## 🎲 1. 2D6 土地探索 システム概要 ＆ 厳格ルール

配置済みの土地ブロックを調査・発掘し、隠された資源（★ ソケット）や古代遺物・即時リソースを獲得する内政パズル要素。

### 📜 1. 探索の基本制約ルール
1. **実行コスト**: 配置済みの土地 1 ブロックにつき **`🔥 -1`** (生命力) を消費して実行。
2. **通算1回のみの回数制限**: **1つの土地ブロックにつき通算 1 回のみ** 実行可能。（※1×1 でも 1 回、探索済みマスは二度と再探索不可）。
3. **マージ土地の探索不可制約**: 2×2 正方形や L字・凸字などの 4 マスマージが完成した合体土地ブロックは **`2D6 探索不可`**。（※マージ前に個別に探索しておくか、★ ソケットを巻き込んでマージするかのジレンマ選択）。
4. **★ ソケット (ボーナス資源) 入手手段の完全一元化**:
   - ドローカードの土地には★ ソケットは一切付与されない。
   - ★ ソケットの開花・獲得手段は **「2D6 土地探索 (出目 9-11)」の成功リワードのみ** に完全一本化・一元管理される。
5. **引き算の UI 視認性設計**:
   - 未探索の土地マスには「探索可能」などのラベルを表示せず、画面ノイズを排除し美しくクリーンな盤面を保持する。
   - **探索を終えたマス (またはマージ済みマス)** にのみ、**`[✓ 探索済]`** アイコンを控えめに表示し、探索完了が一目で判別できるようにする。

## 🧮 2. 2D6 ダイス出目確定報酬マトリクス (不発なし)

探索実行時、2D6（6面体ダイス2個）を振った合計出目によって報酬が確定給付される。

| 2D6 出目 | 判定カテゴリ | 給付報酬 ＆ 発生イベント |
| :---: | :--- | :--- |
| **`2 〜 4` (低出目)** | **少額即時ボーナス** | `🌾 食料` または `🧱 資材` を少額即時獲得（※空振り不発は存在しない）。 |
| **`5 〜 8` (中出目)** | **中額即時ボーナス** | より良い即時資源 (`🌾` / `🧱` / `✨` ※🛡️即時給付全廃) を中額獲得。 |
| **`9 〜 11` (高出目)** | **★ ソケット (ボーナス資源) 開花露出** | 探索した土地の地形 (`H` ✕ `GL`) に適した★ ソケットが開花し、毎ターンの持続収入が増加！ |
| **`12` (素の 6-6 ゾロ目)** | **✨ レアイベント遭遇 (神秘の泉)** | 古代遺跡・『神秘の泉』に遭遇し、大規模な即時回復 ＆ 神秘能力が解禁される！ |

## 📐 3. ブロックサイズ出目補正 ＆ ゾロ目条件

1. **サイズ加算補正**: 未マージの複数マスブロックを探索する際、マス数の大きさに応じて 2D6 ダイス出目にプラス補正が加算される。
2. **出目 12 レアイベント**: 出目 12 のレアイベント遭遇は、サイズ補正込みではなく **「素の 2D6 ダイスで 6-6 のゾロ目が出た場合のみ」** 発動する。

## 🌊 4. ★ ソケット開花 ✕ 水脈発見分岐 (`rules/03_land_system/01_land_base.md` 連携)

★ ソケット（出目 9-11）が開花した際、被せた土地の属性によって特殊水脈地形が確定分岐する。

* **🌾 平地 (H1+GL1) 開花時**: **`25%`** の確率で **『💧 清湖 (Lake)』** が発見される（`🌾 +2/T` ＋ 周囲8マス `灌漑+50%` ＆ `敵減衰-30%`）。
* **🏜️ 砂漠 (H1+GL0) 開花時**: **`25%`** の確率で **『🌴 オアシス (Oasis)』** が湧出昇華される（`🌾 +3/T` ＋ `✨ +5/T` ＋ 開花祝儀 `🔥 +3`）。
