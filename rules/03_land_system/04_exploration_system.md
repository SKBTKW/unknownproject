# 04. 土地探索 — Legacy / 廃止方向

> **Status: Deprecated / Implementation Cleanup Required**
>
> 本文書に旧来記載されていた「配置済み土地を任意選択し、🔥を支払って2D6探索する独立システム」は、現在のゲーム設計では正本ルールとして採用しない。
>
> 探索・発見・調査の体験は、Offeringカード、イベント、ソケット発見、調査・情報系カード等へ分散・統合する方向を採用する。

---

## 1. 現在の設計方針

専用の「土地探索」操作を通常進行の恒常アクションとして持たせない。

理由：

- Verseごとの主要選択を増やし過ぎない
- 盤面上の全土地へ探索済み / 未探索という追加管理を要求しない
- 「とりあえず全マス探索する」作業化を避ける
- 発見体験をカード・イベント・盤面形成へ統合する
- 2D6を、意味のあるイベントや戦術判断へ集中させる

したがって、旧仕様の以下は正本から外す。

- 任意土地をクリックして探索
- 探索専用 `🔥 -1` コスト
- 全土地を1回ずつ探索する管理
- ブロックサイズによる探索出目補正
- 探索専用 2D6 報酬表
- 素の12による探索専用レアイベント
- 地帯化前に探索することを要求するジレンマ

---

## 2. 現在game側に残っている旧実装

`game/src/systems/deck_manager.js` には、旧探索処理 `executeExploration(r, c)` と `LAND_EXPLORATION_CHECK` が残存している。

現行コード上の挙動は概ね以下。

- 対象は配置済み非HQセル
- `cell.searched` によりセル単位1回
- 2D6
- 2〜4: `🌾 +1`
- 5〜7: `🌾 +2`
- 8以上:
  - ソケット未発見なら地形対応ソケットを生成
  - 既存ソケットがある場合 `🌾 +3 / 🧱 +3`
- 水源候補の場合、湖・オアシスの距離 / 逓減ルールを利用

### 旧rulesとの不一致

旧本文書に書かれていた以下は、残存実装とも一致していなかった。

- `🔥 -1` の探索コスト
- ブロック単位で通算1回
- 地帯化済みブロック探索不可
- 9〜11でソケット
- 12で専用レアイベント
- ブロックサイズによる出目補正

つまり旧探索文書は、現行gameの事実を説明する文書としても利用できない。

---

## 3. 実装上の扱い

このLegacy探索コードは、今後 `game/` 側を整理する際の削除・置換候補とする。

ただし本ルール更新作業では `game/` を変更しない。

以下の要素は探索システム削除後も別機構で利用可能。

- `CheckSystem` / 2D6基盤
- socket resource
- 湖 / オアシスの水源生成ルール
- GameplayRandomService

これらは探索専用機能ではないため、独立して維持する。

## 4. 発見体験の移行先

今後の発見・調査は主に以下で扱う。

### Offering / Command Card

- 放棄された集落
- 資源調査
- 地質調査
- 開拓・干拓等のカード

### Global Event

- 世界の異変
- 亜人の痕跡
- 社会・環境イベント

### Investigation / Information

第1 Trial前を中心に、危機の存在を認識した後に解禁される調査・情報カード群。

### 土地開発時の自然発見

湖・オアシス等、一部の水源や特殊要素については土地開発時の発見判定を利用できる。

---

## 5. 2D6の位置づけ

2D6そのものを廃止するわけではない。

2D6は、単純な全土地クリック作業ではなく、以下のような意味のある局面で使用する。

- イベントカード
- 調査・情報
- 神託
- 将来のTrial戦術判定
- その他、結果に物語的・戦略的意味がある判定

汎用ダイス処理の正本は `11_dice_check_contract.md` と `CheckSystem` とする。
