### 📐 土地基礎産出 — E × GL 2変数合成モデル (Single Source of Truth)

各土地1マスの基礎産出は以下の合成関数式によって一意に導出される：

$$Y(E, GL) = T_E(B(GL), GL) = [ \text{🌾 食料}, \text{🧱 資材}, \text{🛡️ 防衛}, \text{✨ 神秘} ]$$

- **`B(GL)`**: 植生繁茂度（何が存在するか）が決定する基礎産出ベクトル
  - `B(0) = [0, 0, 0, 2]` （GL0: 不毛・植生なし）
  - `B(1) = [4, 0, 0, 0]` （GL1: 草本・低密度）
  - `B(2) = [2, 2, 2, 0]` （GL2: 樹木・中密度）
  - `B(3) = [1, 3, 3, 1]` （GL3: 極相・高密度）

- **`T_E(B(GL), GL)`**: 標高・水分・傾斜（人類がどう利用できるか）による環境変換
  - **`E0 (低地)`**: 低湿地変換（※現行仕様では GL1 湿原 のみ自然生成）
    - $\text{🌾} = \lfloor B_{\text{food}} \times 0.5 \rfloor = 2$ （水分過多・排水不良による利用効率低下）
    - $\text{🧱} = B_{\text{material}} = 0$
    - $\text{🛡️} = B_{\text{defense}} + 1 = 1$ （泥濘・水路による進軍阻害・自然防衛）
    - $\text{✨} = B_{\text{mystic}} = 0$
  - **`E1 (平地)`**: 基準面（無補正）
    - $Y(E1, GL) = B(GL)$
  - **`E2 (丘陵)`**: 丘陵変換（傾斜・岩盤・高所）
    - $\text{🌾} = (GL == 0) \ ? \ 0 : \max(1, \lfloor B_{\text{food}} \times 0.5 \rfloor)$
    - $\text{🧱} = B_{\text{material}} + 1 + \lfloor GL / 2 \rfloor$
    - $\text{🛡️} = B_{\text{defense}} + \max(1, GL)$
    - $\text{✨} = B_{\text{mystic}}$
  - **`E3 (山岳)`**: 山岳 Override
    - $Y(E3, GL) = [0, 3, 5, 1]$ 固定

> **【モデルの哲学】**: GL が「土地に何が存在するか」を決め、E が「その土地を人類がどのように利用できるか」を変換する。

- **🌱 同属性土地接続 ✕ 段階的即時リソースボーナス**:
  - 同属性の土地ブロックを繋げて開発した際、置いた瞬間にストックへ直接入る「即時ボーナス (一時金)」が給付される。
  - **1マス開発 (単体)**: 通常の開発 (ボーナスなし)。
  - **2マス目接続 (2度目)**: 確定マトリクス即時ボーナス獲得 (例: 草原 `🌾+5`, 森 `🌾+2/🧱+3`, 丘陵 `🌾+3/🧱+2`, 山岳 `🧱+5/✨+2` ※🛡️即時給付は全廃)。
  - **3マス目接続 (3度目)**: 確定マトリクス拡張即時ボーナス獲得 (※🛡️即時ストック給付全廃)。
  - **4マス目完成（地帯成立）**: 全持続産出 `1.2倍` 増幅 ＋ 即座に `🔥 +1` 給付 (`explorationAllowed: false`)。

- **🗺️ 地勢 ✕ 標高 2大隣接配置制約ルール (気候断絶 ＆ 高度断絶)**:
  - **① 気候断絶ルール (`|GL差| >= 2` 禁止)**:
    - **`GL0 (砂漠・荒野)`** と **`GL2 (森林・森丘陵・山岳)` / `GL3 (深林・森林丘陵)`** は **直接隣接配置不可 (`INVALID_GL_NEIGHBOR`)**。
    - ※ `GL0 (砂漠)` は `GL1 (平地/丘陵/湿原)` または `本営 (HQ)` にのみ隣接可能。
  - **② 高度断絶ルール (断崖制約: `|E差| >= 2` 禁止)**:
    - **4段階の標高体系 (`E0: 低地 ➔ E1: 平地 ➔ E2: 丘陵 ➔ E3: 山岳`)** に基づき、高度差が 2 以上の土地同士は直接隣接配置不可 (`INVALID_ELEVATION_NEIGHBOR`)。
    - **`E0 (低地: 湿原)`** は、水源化していない別の湿原と上下左右へ直接隣接して開発不可。また **`E2 (丘陵)` / `E3 (山岳)`** と直接隣接不可（※ `E0` は `E1 (平地)`、`本営 (HQ)`、湖・オアシスを持つ水源セルに接続可能）。
    - **`E1 (平地: 草原/森/砂漠/深林)`** と **`E3 (山岳)`** は直接隣接不可（※ `E3` を配置するには、隣接マスに `E2 (丘陵)` または `本営 (HQ)` が必要）。
    - ※ この高度断絶ルールにより、盤面には必ず **`低地 (E0) ➔ 平地 (E1) ➔ 丘陵 (E2) ➔ 山岳 (E3)`** という自然で美しい 4 段階の等高線（グラデーション）が形成される。

### ⚓ 複数セル土地のAnchorと全セル隣接合法性

- **Anchorの責務**: Anchorはクリックした盤面座標にShape内のどの基準点を合わせるかだけを定義し、接続・GL/E隣接合法性の判定対象を限定しない。未定義時は `{r:0,c:0}` とする。
- **配置開始座標**: クリック座標を `(clickedR, clickedC)`、回転後Anchorを `{r,c}` としたとき、Shape左上は `startR = clickedR - anchor.r`、`startC = clickedC - anchor.c` で一意に算出する。
- **接続条件**: 回転後Shapeの全構成セルのうち、少なくとも1セルが既存領土へ合法に接続すれば成立する。
- **隣接合法性**: 配置によって生じるすべての既存隣接辺がGL/E等の隣接制限を満たす必要がある。合法な接続が別セルに存在しても、違反辺が1つあれば配置不可とする。
- **論理式**: `ANY(valid connection) AND ALL(valid adjacency)`。
- **回転**: 現在Shapeが `rows x cols`、現在Anchorが `{r,c}` のとき、90度時計回り回転後Anchorは `{r:c, c:rows-1-r}` とし、Shapeと同時に更新する。
- **表示・実行一貫性**: candidate highlight、配置Preview、Validate、実配置は同一の回転後Shape・Anchor座標変換・`canPlaceShape()`を使用する。

## 🌿 2. ★ ソケット（ボーナス資源）開花時の毎ターン持続収入一覧

初期配置された `★` ソケット上を土地で開発する、または 2D6 土地探索（出目 9–11）に成功した際、
開発した土地の **E（標高・水分環境）× GL（繁茂度）** に応じた資源候補から1種を発見する。

各資源は個別IDを持ち、以下に利用できる。

- 毎ターンの追加持続収入
- コマンドカードの解禁条件
- Offering Weight補正
- グローバルイベント条件
- 特殊ブロック配置条件
- ロール固有シナジー

### 資源出現の基本原則

資源には原則として `COMMON / RARE` のような固定レアリティを設定しない。

実際の出現しやすさは、

```text
最終資源Weight
=
資源Base Weight
× 土地属性適性Weight
× 状況補正
```

によって決定する。

そのため、

> 金鉱脈だから「RARE」

ではなく、

> 山岳自体が出にくく、その山岳資源候補の中でも金鉱脈Weightが低いため結果として希少

という自然地理的な希少性を基本とする。

## 🐸 湿原（E0+GL1）

湿原は通常産出では草原より弱いが、
**湖発見・ぬかるみ・迎撃・干拓**などの盤面機能を持つ特殊地形。

基礎産出：

```text
🌾2 🧱0 🛡️1 ✨0
```

水源化していない湿原同士は上下左右へ直接隣接して開発できない。斜めまたは1マス空けた配置、および湖・オアシスを持つ水源セルに隣接する湿原の開発は可能。湿原は地帯化および1×2 / 1×3連結グループへ参加しない。

### 湖発見率

湿原を開発した各マスは、資源ソケットの有無にかかわらず湖発見判定を行う。

```text

資源ソケット上：60%
```

を初期テスト値とする。

草原の25%に対し、湿原では明確に湖を狙えるが、
40%は失敗するため確定変換にはならない。

## 資源発見に関する補足

### 1. 個別資源を統合しない

以下のような複数資源の一括表記は廃止する。

```text
野麦・野生米
杉・楢
鹿・猪
林檎・野苺
大麦・ライ麦
金銀鉱脈
硝石・塩湖
```

それぞれ独立した資源として保持する。

これにより、

```text
馬を発見している
鉄資源を発見している
木材資源を2種類以上発見している
塩を発見している
```

など、個別条件・カテゴリ条件の双方をカードやイベントから参照できる。

---

### 2. 土地属性が資源の出現傾向を決める

同じ資源カテゴリでも、土地によって出現Weightは異なる。

例：

```text
湿原
→ 野生米・水系資源 Weight ↑

草原
→ 野麦・牛・羊 Weight ↑

丘陵
→ 馬・山羊・穀物 Weight ↑

荒野
→ 石材・戦略鉱物 Weight ↑

山岳
→ 鉱脈・貴金属・特殊鉱物 Weight ↑
```

土地属性は資源を確定させるのではなく、

> **どのような資源が発見されやすいか**

を変化させる。

---

### 3. 湖発見率

初期テスト値：

```text
🌾 草原 (E1+GL1)
湖発見率：25%

🐸 湿原 (E0+GL1)
通常マス：20%
資源ソケット上：60%

🏜️ 砂漠 (E1+GL0)
オアシス発見率：25%
```

湿原は湖を狙いやすいが、確定ではない。

### 3.1 水源共通の逓減と近接制約

- 湖（`SOCKET_LAKE`）とオアシス（`SOCKET_OASIS`）を共通して「水源」と数える。
- 発見率には、盤面上の配置済み水源数に応じて次の倍率を掛ける。

| 配置済み水源数 | 発見率倍率 |
| :---: | :---: |
| 0 | `1.00` |
| 1 | `0.70` |
| 2 | `0.40` |
| 3以上 | `0.20` |

- 既存水源からマンハッタン距離2以内（`abs(dr) + abs(dc) <= 2`）では、新しい湖・オアシスを発見できない。ひし形の外周となる距離3以上では発見可能。
- この水源距離制限は土地の開発可否とは分離する。既存水源の距離2以内にも湿原や資源ソケット上の草原を開発できるが、そのセルの湖発見確率は必ず `0%` とする。
- 複数セルを一度に開発する場合も、先に発見した水源を直後のセル判定へ反映する。
- 水源セルは2×2地帯、1×2 / 1×3連結グループ、その他の通常地帯化へ参加しない。

---

### 4. 湿原の役割

湿原は資源産出だけで評価しない。

```text
基礎産出：
🌾2 🧱0 🛡️1 ✨0

地帯化：
不可

特徴：
・湖発見率が高い
・《ぬかるみ》による迎撃価値
・敵進軍経路への干渉
・《干拓》対象
・干拓地から特殊ブロックへ発展
```

草原が直接的な食料経済を担うのに対し、
湿原は**探索・地形戦・土地改良を担う土地**として差別化する。

```text
【干拓地（Reclaimed Land）仕様】
ID: E1_RECLAIMED_LAND
標高 / 繁茂度：E1 / GL1
基礎産出：🌾4 🧱1 🛡️0 ✨0
テーマカラー：青みがかった緑
生成方法：自然生成なし（経済カード《干拓》によって湿原からのみ生成）
特徴：
・草原とは別terrainId（完全一致ルールにより草原と混在した地帯化は不可）
・湿原ではない（湿原固有の配置制限を失い、E1として丘陵への隣接が可能）
・湖発見能力を持たない（湖発見判定は走らない）
・2x2地帯化可能（干拓地4マス同士の2x2地帯化は可能、専用報酬はなし）
・発見済み湖セルは干拓不可（湖は恒久的水源として保護）
・将来的な農業・穀物庫・灌漑・治水などの人工開発システムとの接続を想定
```

---

### 5. 地帯の探索制限


により、地帯化済み土地は2D6土地探索不可とする。

## 🔒 6. 本営近郊 (周囲8マス) での開発制限

- **本営近郊山岳禁止ルール**:
  - 本営（中心マス）の周囲8マス（3×3本営近郊エリア）は、**`E3 山岳` で直接開発不可** とする。

  - 山岳（E3）カードで開発する際は、本営から2マス以上離れた（丘陵等を経由した）外郭エリアのみ開発可能とする。

## 🎯 7. 開発プレビュー時の開発不可理由 一覧ポップアップ表示仕様

- **リアルタイム理由フィードバック**:
  - 土地カード選択状態で盤面上の「開発不可マス」にマウスカーソルを乗せた際、赤色の警告プレビュー枠（`.preview-invalid`）とともに、**「開発できない理由のリスト（該当する全項目）」をツールチップポップアップとして即時フロート表示** する。
- **全違反理由の網羅収集項目**:
  - ❌ **`ERR_NOT_ADJACENT`**: 既存の領土に隣接していません
  - ❌ **`ERR_MOUNTAIN_NEAR_HQ_FORBIDDEN`**: 本営周囲8マスでは山岳を開発できません
  - ❌ **`ERR_INVALID_GL_NEIGHBOR`**: 砂漠と森林・山岳は直接隣接できません（気候断絶）
  - ❌ **`ERR_INVALID_ELEVATION_NEIGHBOR`**: 平地と山岳は直接隣接できません（高度断絶）
  - ❌ **`ERR_ALREADY_PLACED`**: 既に土地が開発されています
  - ❌ **`ERR_OUT_OF_BOUNDS`**: 盤面の外側です

## 💧 8. 水脈ソケット (湖 ＆ オアシス) 周囲8マス灌漑 ＆ 水光エフェクト確定仕様

- **対象水脈ソケット**:
  - **💧 湖 (`SOCKET_LAKE`)**: 湿原・平地等に開花する淡水湖
  - **🌴 オアシス (`SOCKET_OASIS`)**: 砂漠等に開花する緑洲・湧水地
- **2大共通効果**:
  1. **周囲8マスの食料灌漑ボーナス (+50%)**:
     - 水脈ソケット（湖またはオアシス）の周囲 8 マス（3×3 領域）にある食料産出マス（$tf > 0$）に対し、**`食料産出 +50%`（最低 +1）の灌漑ボーナス** を毎ターン付与する。
     - 複数の水源効果範囲が同じマスに重なっても加算せず、そのマスへの灌漑ボーナスは1回だけ適用する。
  2. **周囲8マスの水脈波紋外見エフェクト**:
     - 水脈ソケットが開花した際、周囲 8 マスの未配置マスに **湿原ティール水脈カラー（`#14b8a6`）の 8 方位減衰グラデーション ＆ 水光パルスアニメーション（`lakeVicinityPulse`）** が自動点灯する。
