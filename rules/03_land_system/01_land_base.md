### 📐 土地基礎産出 — E × GL 2変数合成モデル (Single Source of Truth)

各土地1マスの基礎産出は以下の合成関数式によって一意に導出される：

$$Y(E, GL) = T_E(B(GL), GL) = [ \text{🌾 食料}, \text{🧱 資材}, \text{🛡️ 防衛}, \text{✨ 神秘} ]$$

- **`B(GL)`**: 植生繁茂度（何が存在するか）が決定する基礎産出ベクトル
  - `B(0) = [0, 0, 0, 2]` （GL0: 不毛・植生なし）
  - `B(1) = [4, 0, 0, 0]` （GL1: 草本・低密度）
  - `B(2) = [2, 2, 2, 0]` （GL2: 樹木・中密度）
  - `B(3) = [1, 3, 3, 1]` （GL3: 極相・高密度）

- **`T_E(B(GL), GL)`**: 標高・水分・傾斜（人類がどう利用できるか）による環境変換
  - **`E0 (低地)`**: 低湿地変換（※現行仕様では GL1 湿原 のみ自然生成）
    - $\text{🌾} = \lfloor B_{\text{food}} \times 0.5 \rfloor = 2$ （水分過多・排水不良による利用効率低下）
    - $\text{🧱} = B_{\text{material}} = 0$
    - $\text{🛡️} = B_{\text{defense}} + 1 = 1$ （泥濘・水路による進軍阻害・自然防衛）
    - $\text{✨} = B_{\text{mystic}} = 0$
  - **`E1 (平地)`**: 基準面（無補正）
    - $Y(E1, GL) = B(GL)$
  - **`E2 (丘陵)`**: 丘陵変換（傾斜・岩盤・高所）
    - $\text{🌾} = (GL == 0) \ ? \ 0 : \max(1, \lfloor B_{\text{food}} \times 0.5 \rfloor)$
    - $\text{🧱} = B_{\text{material}} + 1 + \lfloor GL / 2 \rfloor$
    - $\text{🛡️} = B_{\text{defense}} + \max(1, GL)$
    - $\text{✨} = B_{\text{mystic}}$
  - **`E3 (山岳)`**: 山岳 Override
    - $Y(E3, GL) = [0, 3, 5, 1]$ 固定

> **【モデルの哲学】**: GL が「土地に何が存在するか」を決め、E が「その土地を人類がどのように利用できるか」を変換する。

- **🌱 同属性土地接続 ✕ 段階的即時リソースボーナス**:
  - 同属性の土地ブロックを繋げて配置した際、置いた瞬間にストックへ直接入る「即時ボーナス (一時金)」が給付される。
  - **1マス配置 (単体)**: 通常配置 (ボーナスなし)。
  - **2マス目接続 (2度目)**: 確定マトリクス即時ボーナス獲得 (例: 草原 `🌾+5`, 森 `🌾+2/🧱+3`, 丘陵 `🌾+3/🧱+2`, 山岳 `🧱+5/✨+2` ※🛡️即時給付は全廃)。
  - **3マス目接続 (3度目)**: 確定マトリクス拡張即時ボーナス獲得 (※🛡️即時ストック給付全廃)。
  - **4マス目完成 (マージ合体)**: 全持続産出 `1.2倍` 増幅 ＋ 即座に `🔥 +1` 給付 (`explorationAllowed: false`)。

- **🗺️ 地勢 ✕ 標高 2大隣接配置制約ルール (気候断絶 ＆ 高度断絶)**:
  - **① 気候断絶ルール (`|GL差| >= 2` 禁止)**:
    - **`GL0 (砂漠・荒野)`** と **`GL2 (森林・森丘陵・山岳)` / `GL3 (深林・森林丘陵)`** は **直接隣接配置不可 (`INVALID_GL_NEIGHBOR`)**。
    - ※ `GL0 (砂漠)` は `GL1 (平地/丘陵/湿原)` または `本営 (HQ)` にのみ隣接可能。
  - **② 高度断絶ルール (断崖制約: `|E差| >= 2` 禁止)**:
    - **4段階の標高体系 (`E0: 低地 ➔ E1: 平地 ➔ E2: 丘陵 ➔ E3: 山岳`)** に基づき、高度差が 2 以上の土地同士は直接隣接配置不可 (`INVALID_ELEVATION_NEIGHBOR`)。
    - **`E0 (低地: 湿原)`** と **`E2 (丘陵)` / `E3 (山岳)`** は直接隣接不可（※ `E0` は `E1 (平地)` または `本営 (HQ)` にのみ隣接可能）。
    - **`E1 (平地: 草原/森/砂漠/深林)`** と **`E3 (山岳)`** は直接隣接不可（※ `E3` を配置するには、隣接マスに `E2 (丘陵)` または `本営 (HQ)` が必要）。
    - ※ この高度断絶ルールにより、盤面には必ず **`低地 (E0) ➔ 平地 (E1) ➔ 丘陵 (E2) ➔ 山岳 (E3)`** という自然で美しい 4 段階の等高線（グラデーション）が形成される。
