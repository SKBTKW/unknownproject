# 02. 第1スロット属性（緑の深さ）

## 現在の属性一覧

| 緑の深さ | 🌾食料 | 🧱資材 | 🛡️防衛力 | ✨神秘 | 開発可否 | レアリティ | 備考 |
| -------- | ------ | ------ | -------- | ------ | -------- | ---------- | ---- |
| **密林** | -15    | +5     | +20      | +5     | 可       | R          | 🌾にペナルティあり、🧱・🛡️にボーナス、✨に微量ボーナス |
| **森**   | -10    | +10    | +10      | 0      | 可       | UC         | 🌾にペナルティあり、🧱・🛡️にボーナス |
| **標準** | 0      | 0      | 0        | 0      | 可       | C          | 産出への影響なし。デフォルト状態 |
| **砂漠** | -20    | 0      | 0        | +10    | 可       | R          | 神秘を産出。預言者との相性良好。ただし食料に大きなペナルティ |

## 重要なルール

- 属性は**1土地につき最大1つ**まで付与可能（第1スロット）
- 川を特性に持つ土地は**開発不可**
- 森・砂漠は開発可能だが、開発時に特性の扱いが変わる（詳細は03_development.md参照）
- 場の属性構成が、ドローカテゴリ「土地特性付与」の出現に影響する

## 設計意図

属性を付けることで「この土地をどう育てるか」の選択肢を増やし、プレイの幅を広げる。特に川と砂漠は明確な個性を持たせ、戦略の分岐点になるように設計している。
