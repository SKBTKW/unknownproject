# 04. ドロー ＆ 手札 ＆ カードビジュアル 確定仕様

## 🎴 1. 6大ドローカテゴリ (手札オファリング提示カード)

毎ターン山札から 3 枚提示される手札オファリングカードは、以下の **6 大カテゴリ** に分類されます。

1. **【🌱 土地ブロック (Land)】**:
   - 草原(GL1)、森(GL2)、深い森(GL3)、丘陵(H2)、山岳(H3)、砂漠(GL0) などの各形状ブロック。
2. **【🏗️ 施設・防衛 (Facility & Military)】**:
   - 土地の上に設置する固定建築カード（前哨塔、防壁、見張り台、水車など）。
3. **【🌾 産業・生産 (Industry & Civil)】**:
   - リソース産出や回収効率を高める内政カード（大開墾、山林伐採、資材蓄積など）。
4. **【✨ 神秘・祈祷 (Mystic & Prayer)】**:
   - 神秘力を集め、🔥自家発電や天啓を引き起こす神聖カード（祈祷の儀、残り火の捧げ物など）。
5. **【📜 社会・制度 (Polity & Policy)】**:
   - 文明の制度や集落の規律を高めるパッシブカード（黄金期の到来、労働規律など）。
6. **【🔮 特別・レジェンド (Legend & Ultimate)】**:
   - 各指導者の奥義や一発逆転カード（預言者の大天啓、難攻不落の要塞化など）。

*(※ 拠点 (Outpost) の建設、城市への発展、街道の敷設、スキルツリーのノード解放は、ドローカードではなく、プレイヤーがリソース 🧱/🔥 を消費して能動的に実行する【建築・技術システム】であり、ドローカードとは明確に分離される)*

## 🔒 2. 条件判定 ＆ 動的カードプールフィルタリング

- **🚫 出現条件非対象カードの完全除外 (条件動的フィルタリング)**:
  - 場の状況（例: 森の有無、🌾蓄積量、特定土地の数など）をリアルタイム判定し、出現条件を満たしていないカードはドロー提示の選択肢から **100% 物理除外** される。
- **✨ 最適配置時の『相応のビジュアル演出ガイド』 (文字説明ゼロの直感UX)**:
  - 手札のカードをドラッグホバーさせた際、文字テキストで指示を出さず、**「最適・シナジーが高い配置」に対して相応のビジュアル演出** が発生し、プレイヤーの自力発見を直感誘導する。
    - **✨ 2×2 マージ成立予兆**: 4マス全体が黄金の輝きと合体シルエットでパッと光る。
    - **💧 水源 (湖) 恵み発動予兆**: 波紋と緑の粒子が舞い、産出ブースト(+50%)の成立を示す。
    - **🛡️ 高度・風土シナジー成立予兆**: 防衛マークやグラデーション光がパッと浮かび上がる。
    - **手札超過廃棄とタクティクス生成**: 手札超過時の捨て札は戦術カード（タクティクス）生成の資源として活用される。

## 📊 3. 場の傾向反映と追加ルール

- **📊 場の傾向のリアルタイム反映 (Dynamic Weighting)**:
  - ドローの出現確率は静的ではなく、現在の盤面の状態（場の傾向: 森林率、山岳数、リソース蓄積傾向など）をリアルタイムに反映して確率が連動・変化する。
- **⚡ 突発ランダムイベントの完全独立構造**:
  - ターン開始時等に起こるシステム主導の突発ランダムイベント（気候乾燥、地質変動、突発アクシデント等）は、**場の傾向やプレイヤーの盤面都合とは 100% 無関係** に独立して発生する。
- **リソース消費マリガン (手札全引き直し)**:
  - **`🔥 -3`** 消費して手札3枚をすべて引き直し可能（1ターン最大1回のみ）。
- **保留スロット (0/3 枠)**:
  - 最大 3 枚までカードを保留枠へキープ可能。
  - 保留枠にカードが存在するターン開始時、維持費として **`-1 🔥`** 自動消費。
- **🔄 土地カード回転操作UI**:
  - カード表示UIの煩雑化を防ぎ全体デザインを統一するため、**カード枠内の回転ボタンは削除・撤去**される。
  - 土地カードの回転操作は**「対象カードの右クリック」**（および `R` キー）によって即座に90度回転が行われる。全カードのカード最下部ボタンは**「保留」ボタン1個のみ**で完全に美しく統一される。

## 🎴 3. 確定 4 大ドローカテゴリ ✕ 即効発動コスト構造

ドローカードは「パッシブ効果」や「自動トリガー」ではなく、**「引いたターンに手札からコストを支払って使用（キャスト）し、即座に盤面や全体ステータスを一時的・即効的に変容させる使い切りコマンド」** と定義されます。

### 1. 🌱 【土地・地形 (Land Cards)】 （発動コスト: 無償）
* **意義**: 盤面へ配置し、領土を広げ、毎ターンの基礎産出（持続性）を育てる素材。
* **価値**: 未来への持続的投資 ✕ 2×2マージ・1周包囲リングの核。

### 2. 📜 【経済・政策 (Economy Cards)】 （発動コスト: 🌾 食料消費）
* **意義**: 蓄積した食料を消費し、既存の開拓地へ『土地改善（農具導入・増収）』を行い、即座に大量の資材や他リソースを一括獲得・大幅増収させる。
* **価値**: 今すぐ建設や発展を行いたい時の、即時大ジャンプ力。

### 3. 🛡️ 【防衛・軍事 (Military Cards)】 （発動コスト: 🧱 資材消費）
* **意義**: 蓄積した資材を消費し、グローバル防衛力 `🛡️` や本営防壁を一気に跳ね上げる。
* **価値**: 迫り来る試練（T15, T30等）を無傷で乗り切るための緊急サバイバル。

### 4. ✨ 【恩寵・奇跡 (Mystic Cards)】 （発動コスト: ✨ 神秘消費）
* **意義**: コツコツ溜めた神秘を消費し、土地の浄化変容・残り火回復・古代神鋼の精錬などの超常現象を起こす。
* **価値**: 絶体絶命のピンチや土壇場を一発で覆す大逆転力。

## 📐 4. 試練突破による Stage 昇格 ＆ ブロック形状の段階アンロック

試練を突破して盤面が拡張されるのに合わせ、ドロープールに出現する土地ブロックの形状が段階的にアンロックされる。

- **🟢 Stage 1 (5×5 盤面 / ゲーム開始 〜 第1試練突破まで)**:
  - ドロー出現形状: **`1〜2マス (1×1, 1×2)`** のみ。（🔒 3マス以上の大型形状は出現不可）
- **🔵 Stage 2 (7×7 盤面 / 第1試練突破後 〜 第2試練突破まで)**:
  - ドロー形状解禁: **`3マス (1×3, 3マスL字)`** が解禁！ ＋ 本営産出 **1.4倍**！（🔒 4マス以上のブロックは出現不可）
- **🟡 Stage 3 (9×9 盤面 / 第2試練突破後 〜 50T完走まで)**:
  - ドロー形状解禁: **`4マス全ブロック (1×4直線, 4マスL字, 4マス凸型, 2×2正方形)`** が一挙解禁！ ＋ 本営産出 **1.8倍**！

*(※試練発生には±3Tのブレが存在するため、固定ターン数ではなく「各試練のクリア（突破）」によって動的にStage昇格・形状アンロックが行われる)*

### 2. 確率ウェイト配分補正 (Stage 別動的抽選)

- **🌾 平地**:
  - Stage 1: `1x1` (80%), `1x2` (20%)
  - Stage 2: `1x1` (60%), `1x2` (30%), `1x3 L字/直線` (10%)
  - Stage 3: `1x1` (45%), `1x2` (35%), `1x3` (10%), `1x4 / 2x2` (10%)
- **⛰️ 丘陵**: `1x2` (60%), `1x3 L字` (30%), `1x4 L字` (10%)
- **🏔️ 山岳**: `1x3 直線` (60%), `1x4 凸型` (30%), `1x4 直線` (10%)
- **🌲 森**: `1x1` (70%), `1x2` (30%) （常時固定）

### 1. Stage 昇格ごとの「ドロー出現率 (係数 / 確率ウェイト) マトリックス」

ドロープールに出現するカードのレアリティ確率は、Stage（盤面サイズ・試練突破状況）に応じて以下のように動的に変化・補正される。（※⚪ C と 🟢 UC を 90% 以上の絶対メイン軸とし、R 以上の大型土地や強力コマンドを厳格に稀少化した超硬派サバイバルバランス）

* **🟢 Stage 1 (5×5 盤面 / 初期状態)**:
  * **⚪ C (コモン: 1×1土地等)**: **`80%`** (※基礎1×1土地が手札の8割を占める)
  * **🟢 UC (アンコモン: 1×2土地等)**: **`20%`**
  * *(🔒 R / UR / Legend は物理的に出現不可)*

* **🔵 Stage 2 (7×7 盤面 / 第1試練突破後)**:
  * **⚪ C (1×1)**: **`68%`**
  * **🟢 UC (1×2)**: **`27%`**
  * **🔵 R (1×3, 1×4異形, Rコマンド)**: **`4.5%`** (※厳格激減調整)
  * **🟣 UR / 🟡 Legend (2×2, Lコマンド)**: **`0.5%`** (※超極稀な奇跡枠)

* **🟡 Stage 3 (9×9 盤面 / 第2試練突破後)**:
  * **⚪ C (1×1)**: **`60%`**
  * **🟢 UC (1×2)**: **`31%`**
  * **🔵 R (1×3, 1×4異形, Rコマンド)**: **`6.5%`** (※厳格激減調整)
  * **🟣 UR (2×2土地)**: **`2.0%`** (※厳格激減調整)
  * **🟡 Legend (超絶コマンド)**: **`0.5%`** (※真の伝説枠)

### 2. カード種別ごとの「枚数制限（上限）」とレアリティ体系

土地ブロックカードおよびコマンドカードにおける、1ラン（1ゲーム）通算の配置・発動上限ルール。インフレを防ぎ、かつ序盤〜中盤の自由な開墾感を確保するため、**土地ブロックの枚数制限は R 以上（R, UR, Legend）のみに通算適用**される。

#### 📄 【確定版】R以上 土地枚数制限ルールマトリクス

| レアリティ | 代表的な土地タイプ | 1ラン通算の配置上限 | ルール詳細・デザイン意図 |
| :--- | :--- | :---: | :--- |
| **⚪ C (コモン)** | 1x1 基本土地 (草原・森など) | **無制限** | 自由な開墾の土台。何枚でも配置可能 |
| **🟢 UC (アンコモン)**| 1x2 主力土地 (草原・森など) | **無制限** | 盤面を広げる主力インフラ。窮屈感なく自由に配置 |
| **🔵 R (レア)** | 1x3 土地、1x2 複合地勢など | **通算 6 枚** | 種類が複数あっても、**R全体で通算 6 枚** に達するとドロー出現終了 |
| **🟣 UR (ウルトラレア)**| 2x2 土地など | **通算 2 枚** | 2x2大土地。**UR全体で通算 2 枚** に達するとドロー出現終了 |
| **🟡 Legend** | 聖なる光脈などの切り札地勢 | **通算 1 枚** | 切り札地勢。**1ランで通算 1 枚のみ** 配置可能 |

* ※ 上限に達したレアリティのカードは、自動的にドロープールから除外され、下位レアリティまたはコマンド枠へ自動繰り下げされる。

* **📜/🛡️/✨ コマンドカード (使い切り効果)**:
  * **⚪ C / 🟢 UC**: 何度でもドロー可能。
  * **🔵 R / 🟡 Legend**: **`1 ランで最大 1 枚のみ (重複不可のユニーク制限あり)`**。

### 3. 確定出現ハックを遮断する「2 段階・確率分離アルゴリズム」
条件の絞り込みによって特定のレアカードが確定（100%）で出現してしまうメタハックを防ぐため、以下の 2 段階処理を強制適用する。
* **第 1 段階 (枠の独立ダイスロール)**: 条件判定の『前』に、オファリング 3 枠のレアリティ（Common/Uncommon/Rare/Legend）を純粋な独立確率で確定させる。
* **第 2 段階 (条件適合チェック)**: 例えば 3% の Legend 枠が確定した場合にのみ、その時点で出現条件を満たしているレジェンドカードから抽出する。（※条件適合なしの場合は Rare へ繰り下げ）

## 🟡 5. 超絶 Legend ユニークカード代表例: 『✨ 未知なる神鋼の発見』

* **出現条件**: `✨ 神秘 30 以上保有` ＆ `★ 貴金属鉱山ソケット（便宜上）を開拓獲得済み`
* **発動コスト**: `✨ 30` 消費 (神鋼の精錬コスト)
* **絶大効果 (スレスパ型可変爆発)**:
  * **即時還元**: 即座に **`🧱 +20` (資材) 一括獲得**！
  * **場の山岳の数により可変**: 全体産出に `✨+3/T` ✕ `🧱+5/T` ✕ **`(盤面上の山岳・鉱脈数 ✕ 🛡️+8/T)`** が即座に永久加算！
* **🔥 重厚な代償 (アップキープコスト / 毎ターンの維持費)**:
  * 毎ターンの開始時、神鋼の炉を維持するための代償として **`毎ターン 🌾 5 (食料)`** を自動消費する。
* **⚠️ 支払不能ペナルティ (一時休眠化)**:
  * 食料不足で `🌾 5` が払えないターンは神鋼の炉が冷えて一時的に機能停止（🛡️ ボーナス一時失効）。※食料が回復すれば即座に 100% 自動復旧。

## 🎨 6. カードビジュアル 4重レイヤー構造 (Card Layer Architecture)

全カードはスーファミ風レトロドット絵と現代的モダンUIが融合した共通の4重レイヤーで構成されます。

1. **最下層 (Bottom Layer)**: スーファミ風 16-bit レトロドット絵メインイラスト
2. **中層 (Middle Layer / レアリティ枠)**: レアリティ別モダン質感フレーム
   - **C (コモン)**: ダークブロンズ枠
   - **UC (アンコモン)**: ネオンシルバー枠
   - **R (レア)**: クリスタルゴールド枠 (※1プレイ1回限定ユニーク)
   - **L (レジェンド)**: プレミアムプラチナ枠 (※1プレイ1回限定ユニーク)
3. **上層 (Upper Layer)**: 各種パラメータ (`🌾🧱🛡️✨`) ＆ 効果テキスト
4. **表面 / オーバーレイ (Surface Layer)**: H/GL地形属性 ＆ ミニマップ形状アイコン ＆ ★ソケット（金の光粒きらめき）

## 📜 7. イベント発生条件 (8 大トリガートラッキング仕様)

イベント（突発イベント / 確定イベント）は、プレイヤーの盤面状態・戦闘結果・リソース消費・経過ターンなどをトリガーとして発生判定が行われます。**(※以下はトリガー条件の代表的な一例であり、今後の開発に応じて柔軟に拡張・追加されます)**

1. **マージブロックの存在**: 盤面上に 2×2 / L字 / 凸字 のマージ合体ブロックが存在する時 (`hasMergedBlock >= 1`)。
2. **湖の存在**: 盤面上にレアドット絵アセット『清湖 (Lake)』が存在する時 (`hasLakeOnBoard >= 1`)。
3. **高産出ブロックの存在**: 1 マスの産出量が一定閾値以上の高産出土地が存在する時 (`maxTileYield >= 閾値`)。
4. **拠点の存在**: 盤面上に拠点（Outpost）が存在する時 (`outpostCount >= 1`)。
5. **試練での損害（与えた）**: 直前の試練フェーズで敵亜人・怪物へ一定以上のダメージ/撃破を与えた時 (`lastTrialDamageDealt >= A`)。
6. **試練での損害（受けた）**: 直前の試練フェーズで自陣が一定以上の被ダメージ/施設破壊を受けた時 (`lastTrialDamageTaken >= B`)。
7. **✨ による効果発動**: 神秘（✨）を消費するコマンドカードや効果を発動した時 (`hasUsedMagicThisTurn`)。
8. **🔥 消費 ✕ 経過ターン**: 累計一定数以上の残り火（🔥）を消費し、かつ一定ターン数が経過した時 (`totalEmberSpent >= C && currentTurn >= D`)。

## 🎴 4. 盤面共鳴ドロー (Alignment Resonance Draw) 確定理想仕様

毎ターンの手札オファリング（3択ドロー）は静的固定ではなく、プレイヤーが盤面をどうデザインしているか（盤面のこだわり）に応じて、出現カードの傾向がリアルタイムに緩やか・段階的に変化・共鳴する。

### 4.1. 🏛️ 管理負荷ゼロの原則 (No-Management Principle)
- 施設やカードに対し、毎ターンの耐久度管理や数値カウント追跡等の「維持管理ストレス」を一切課さない。
- 施設要素は「設置時1回使い切りの戦術トラップ/即時給付」、「既存土地への上書きトッピング」、または「2×2マージ完成時に自動出現する象徴ランドマーク」として扱い、管理負荷 0 を徹底する。

### 4.2. 🧮 熟練度に応じた 2 段階ドローコントロール
- **🟢 ライト層 (感覚的配置 / 単体置留め)**:
  - 砂漠や清湖を単に数マス置いている段階では、「なんとなく自分の選んだ土地が出やすくなっている気がする…」と感じる微弱な隠し味バイアス (想定: +8〜10% 程度) に抑える。
  - 露骨な手回し感を全廃し、自分の直感と幸運が自然に噛み合っている心地よい手触りを優先する。
- **🔴 熟練層 (高度構築 / マージ・8マスコンプ・グラデーション完成)**:
  - ルールを理解したプレイヤーが「2×2 マージ」「周囲8マスコンプリート」「高度/気候グラデーション」などの高度な地政学条件を達成した際、該当シナジーカードのドロー出現補正を一気に強力ステップアップさせる (想定: +25〜50% 程度)。
  - ルール熟知者に対し、「狙ったトッピングカードや特化カードを盤面構築によって意図的に手繰り寄せる（手札をコントロールする）」圧巻の知的快感を確定提供する。

*(※具体的な補正パーセンテージ数値は、今後の実機テストプレイでの手触り・感触の検証を経て最終微調整を行う)*
