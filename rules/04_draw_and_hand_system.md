# 04. ドロー ＆ 手札 ＆ カードビジュアル 確定仕様

## 🃏 1. ドローオファリング ＆ 選択ルール

- **ドローオファリング**: 毎ターン山札から **手札 3 枚** が提示される。
- **選択ロック (1ドロー1プレイ)**: 手札3枚から **1枚 を選択した時点で、残りのカードは即座に選択不可（グレーアウト）** となり、手札配置権が確定する。
- **リソース消費マリガン (引き直し)**:
  - **`1 🔥`** 消費して手札3枚をすべて引き直し可能（1ターン最大1回）。
- **保留スロット (0/3 枠)**:
  - 最大 3 枚までカードを保留枠へキープ可能。
  - 保留枠にカードが存在するターン開始時、維持費として **`-1 🔥`** 自動消費。

## 📐 2. 試練突破による Stage 昇格 ＆ レアリティ解禁

- **Stage 1 (5×5 盤面 / ゲーム開始 〜 第1試練突破まで)**:
  - ドロー出現: **`C (1×1)`** および **`UC (1×2, 1×3)`** のみ。（🔒 R・L はドロー不可）
- **Stage 2 (7×7 盤面 / 第1試練突破後 〜 第2試練突破まで)**:
  - ドロー解禁: **`🔓 R (1×4 4マスブロック)`** 解禁 ＋ 本営産出 **1.4倍**！
- **Stage 3 (9×9 盤面 / 第2試練突破後 〜 50T完走まで)**:
  - ドロー解禁: **`🔓 L (2×2 正方形)`** 解禁 ＋ 本営産出 **1.8倍**！

*(※試練発生には±3Tのブレが存在するため、固定ターン数ではなく「各試練のクリア（突破）」によって動的にStage昇格・解禁が行われる)*

## 🎨 3. カードビジュアル 4重レイヤー構造 (Card Layer Architecture)

全カードはスーファミ風レトロドット絵と現代的モダンUIが融合した共通の4重レイヤーで構成されます。

1. **最下層 (Bottom Layer)**: スーファミ風 16-bit レトロドット絵メインイラスト
2. **中層 (Middle Layer / レアリティ枠)**: レアリティ別モダン質感フレーム
   - **C (コモン)**: ダークブロンズ枠
   - **UC (アンコモン)**: ネオンシルバー枠
   - **R (レア)**: クリスタルゴールド枠 (※1プレイ1回限定取得)
   - **L (レジェンド)**: プレミアムプラチナ枠 (※1プレイ1回限定取得)
3. **上層 (Upper Layer)**: 各種パラメータ (`🌾🧱🛡️✨`) ＆ 効果テキスト
4. **表面 / オーバーレイ (Surface Layer)**: H/GL地形属性 ＆ ミニマップ形状アイコン ＆ ★ソケット
