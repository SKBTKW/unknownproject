## 🎨 デザイン ＆ ビジュアル確定仕様

- **アートディレクション**: スーファミ風 (16-bit SFC) レトロドット絵 ✕ 現代的高級モダン UI (Glassmorphism)
- **4重レイヤー基本フォーマット**:
  1. 最下層 (Bottom): SFC風レトロドット絵メインイラスト
  2. 中層 (Middle): レアリティ別モダンフレーム (`C:ブロンズ`, `UC:ネオンシルバー`, `R:クリスタルゴールド`, `L:プラチナ`)
  3. 上層 (Upper): リソースパラメータ ＆ テキスト
  4. 表面 (Surface): H/GL属性 ＆ ミニマップ形状アイコン ＆ ★ソケット

## 🛠️ プロジェクト開発・更新方針

1. **実機検証優先**: パターン推測のみでの完了報告を禁止し、コード・実機動作検証を経て更新すること。
2. **ローカライズ遵守**: コード内直書きを避け、多言語キー経由で管理すること。
3. **積み上げ巻き戻し破壊の禁止**: ランダム天変地異による建造物・土地の永続消滅を100%排除すること。
